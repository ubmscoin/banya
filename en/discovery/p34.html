Core Finding

P-34: Neutron EDM $d_n=\alpha^8$ Scale $\sim10^{-30}\,e\!\cdot\!$cm

$$d_n\sim\theta_\text{QCD}\cdot\frac{e}{m_n c}\sim\alpha^8\cdot\frac{e}{m_n c}\sim10^{-30}\,e\!\cdot\!\text{cm}\quad(\theta_\text{QCD}=\alpha^8\sim10^{-17})$$

Prediction: neutron EDM $d_n\sim10^{-30}\,e\!\cdot\!$cm ($\alpha^8$ scale). Test: nEDM@SNS (2028~).

In the Banya formula $\delta^2=(\text{time}+\text{space})^2+(\text{observer}+\text{superposition})^2$, the strong-CP angle $\theta_\text{QCD}$ is fixed to $\theta_\text{QCD}=\alpha^8\sim10^{-17}$ as one period of the 8-bit d-ring buffer passes the CAS selection cost $\alpha$ eight times (Axiom 15, P-13, P-25).

The neutron electric dipole moment (nEDM) $d_n$ is proportional to this CP-violating angle — $d_n\sim\theta_\text{QCD}\times e/(m_n c)$.

Inserting $\theta_\text{QCD}=\alpha^8\sim10^{-17}$ gives $d_n\sim10^{-30}\,e\!\cdot\!$cm. This is essentially the nEDM-observable version of P-25 (strong CP).

This value is about 4 orders below the current experimental limit ($d_n<10^{-26}\,e\!\cdot\!$cm) ==> it should be invisible to the present generation of experiments.

So this prediction is not "the nEDM is small" but the quantitative claim "exactly $\alpha^8$ scale ($\sim10^{-30}$)," arising directly from the d-ring bit count 8.

The standard axion solution also predicts small $\theta$ but cannot fix the value — the Banya framework fixes it to $\alpha^8$ (and the axion is unnecessary in P-25).

Conversely, many BSM (beyond-Standard-Model) models predict large values $d_n\sim10^{-28}$–$10^{-27}$, close to current sensitivity — this is the discriminator.

Observationally, the nEDM is measured from the difference in neutron precession frequency under magnetic and electric fields.

Test: if nEDM@SNS (2028~) reaches $10^{-28}$ sensitivity and still sees zero signal, it supports this prediction ($\sim10^{-30}$).

Refutation: if $d_n>10^{-27}\,e\!\cdot\!$cm is measured, the $\alpha^8$-scale prediction breaks and this prediction is discarded.
