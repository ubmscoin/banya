H-452. Quantum Eraser = Discarding the Compare Result Before Swap

Core Finding

H-452: Quantum eraser = discarding the Compare result before Swap

$$\text{which-path info erased} \;\text{<==>}\; \text{Compare result discarded before Swap} \;\text{==>}\; \text{interference restored}$$

Grade: B

In a double slit, once a which-path marker (the Compare result) is recorded, interference disappears (H-447: Swap executed ==> path determined). However, if that marker is discarded before Swap (i.e. the Compare result is evicted from the d-ring), the system returns to a Compare-false state and superposition is retained -- the interference fringes come back. CAS view: if the Compare result does not lead to Swap, the DATA is unchanged, so the superposition index (Axiom 13) survives intact.

Axiom 7 (gap between Compare and Swap), Axiom 13 (persistence of the superposition index)

Axiom 7 (Compare result ==> condition for Swap execution) ==> Axiom 2 (in R ==> C ==> S, the C result can be discarded before S) ==> Axiom 13 (index not erased ==> superposition retained) ==> Axiom 8 (polling timing).

The quantum eraser is not "erasing the past" but "not executing the Swap". In the R ==> C ==> S pipeline of CAS, discarding the result at stage C means stage S is never reached. The result: DATA unchanged ==> superposition retained ==> interference restored. Causality preservation: the erasure decision must always happen before Swap, and subset selection is only possible after the classical channel has arrived.

Kim (2000) delayed-choice quantum eraser: fringes restored along the erasure path, fringes destroyed along the non-erasure path. Consistent with the CAS model.

Consistent with Walborn (2002) experimental results.

Quantum eraser (Scully-Drühl 1982), delayed-choice quantum eraser (Kim 2000).
