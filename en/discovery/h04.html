Core Finding

H-04: baryon = CAS commit, meson = open transaction

In CAS, when all three stages Read ==> Compare ==> Swap complete, the result is a commit (111). A baryon (proton, neutron) is a complete entity built from three quarks and corresponds to a CAS commit. A meson is a quark-antiquark pair and corresponds to an open CAS transaction (a pre-commit state).

In δ² = (t+s)² + (o+sp)², when CAS fully completes its write (juim) into DATA, the d-ring is closed. baryon = d-ring fully closed (R=1, C=1, S=1 ==> 111). meson = d-ring open (the quark-antiquark share the ring seam but it is not sealed).

Axiom 2 (CAS sole operator) ==> Axiom 7 (write = juim) ==> Axiom 14 (FSM declaration). Once the FSM cycle IDLE ==> Read ==> Compare ==> Swap ==> IDLE completes, it cannot be reversed. Swap's irreversibility (Axiom 14) is the irreversibility of the commit.

Baryon-number conservation = commit-count conservation. A CAS commit (111) is the sealed state of the FSM, so no rollback path exists. This is why the proton does not decay. A meson is an open transaction, so the CAS cycle can be cancelled before completion. That is why mesons are unstable.

Proton lifetime > 10³⁴ years (experimental lower bound). If a CAS commit is truly irreversible, the proton lifetime is infinite. If GUT proton decay (10³⁶ years) is observed, that would mean CAS atomicity has an exception.

Super-Kamiokande has not observed proton decay; the current lower bound is 1.6×10³⁴ years. No contradiction with the CAS prediction (infinite).

In the Standard Model, baryon-number conservation is an accidental symmetry; it is broken in GUTs. In the Banya Framework, it is a structural necessity from FSM completion.

GUTs (SU(5)) predict proton decay (lifetime ~10³⁵ years). The Banya Framework predicts that if CAS atomicity is absolute, proton decay does not exist. Hyper-Kamiokande can decide.

Refutation condition: an observation of proton decay would break the absolute irreversibility of the CAS commit. Observation of sphaleron processes (baryon-number change at the electroweak phase transition) would mean CAS atomicity has a temperature-dependent exception.

Open work: the sphaleron process must be interpreted in the CAS frame. At high temperatures (electroweak phase transition), the FSM path IDLE ==> Read ==> Compare ==> Swap could be perturbed by thermal fluctuations. We need to investigate whether the commit is being cancelled or a new CAS cycle is being executed in the reverse direction.
