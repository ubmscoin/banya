H-995. Riemann zeros = domain-time frequencies: the phase variable of the explicit formula is $\log x = t_\text{dom}$

Key finding

H-995: in Riemann's explicit formula the wave contributed by one zero rotates in $\log x$, not in $x$ -- the same variable as Banya's domain time $t_\text{dom} = \log T_\text{sys}$

$$x^{\rho} = x^{\beta}\, e^{\,i\gamma \log x}, \qquad x = T_\text{sys} \;\Rightarrow\; x^{\rho} = x^{\beta}\, e^{\,i\gamma\, t_\text{dom}}$$

Hypothesis -- a variable correspondence, not a numerical hit. The imaginary part $\gamma$ of a zero $\rho = \beta + i\gamma$ reads as an angular frequency in domain time

In the explicit formula $\psi(x) = x - \sum_\rho x^\rho/\rho - \log 2\pi - \tfrac12\log(1-x^{-2})$ the left side $\psi(x) = \sum_{p^k\le x}\log p$ is a staircase over the integers. The oscillatory terms depend on $x$ only through the amplitude $x^\beta$ and the phase $\gamma\log x$. Reading the integer $x$ as a count of CAS cycles (Axiom 2 proposition "CAS is an operator outside time": system time = number of CAS cycles), the phase variable $\log x$ sits exactly where Axiom 15 proposition "system time and domain time differ" puts domain time = the logarithm of system time. One zero is a single frequency in domain time; the zero spectrum is the frequency list of domain time.

The phase factor $e^{i\gamma\log x}$ has the form of the Axiom 1 proposition (unit-circle form of the Banya equation) $e^{i\theta} = \cos\theta + i\sin\theta$ with $\theta = \gamma\, t_\text{dom}$. Literature consistency: in the Hilbert-Polya programme, the Berry-Keating candidate $H = xp$ has classical trajectories $x(t) = x_0 e^{t}$, whose time variable is exactly $t = \log x$ (Berry-Keating 1999). The logarithmic time that the literature obtains from a Hamiltonian candidate, Banya obtains from the axiomatic separation of time layers.

Re-substitution use: bridges D-143 ($t_\text{dom} = \log T_\text{sys}$) and H-424 (domain-time quantization $\log(n+1)-\log n$) into number theory. Together with H-996 (amplitude exponent 1/2) it covers phase and amplitude of the explicit formula.

Why it stops at Hypothesis: identifying the integer $x$ with the system tick count is an interpretation, not forced by the axioms. The zero values themselves ($\gamma_1 = 14.134725\ldots$) are not produced. This is a retrospective reconstruction on a known mathematical identity.

Five-step recursive substitution: reading the phase variable of the explicit formula as domain time

Step 1. Banya equation

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

The staircase $\psi(x)$ is defined by a sum $\Sigma$ over integers, built only from the operations Axiom 3 allows on DATA ($\Sigma$, mod $N$, AND, shift, difference). The smooth and oscillatory terms on the right belong to the Axiom 3 description "a continuous distribution projected onto DATA as an approximation". This card treats only the phase variable of the oscillatory terms.

Step 2. Norm substitution

$x^{\rho} = e^{\rho\log x} = x^{\beta}\,e^{i\gamma\log x}$
$x = T_\text{sys}$ (number of CAS cycles), $\log x = t_\text{dom}$ $\Rightarrow$ $x^\rho = x^\beta e^{i\gamma t_\text{dom}}$
$\rho = \beta + i\gamma$: nontrivial zero | $T_\text{sys}$: system time (Axiom 2 proposition) | $t_\text{dom}$: domain time = log of system time (Axiom 15 proposition) | $e^{i\theta}$: unit-circle form (Axiom 1 proposition)

Step 3. Constant substitution

$\gamma_1 = 14.134725,\; \gamma_2 = 21.022040,\; \gamma_3 = 25.010858,\; \gamma_4 = 30.424876,\; \gamma_5 = 32.935062$ (Odlyzko tables)
One domain-time period: $\Delta t_\text{dom} = 2\pi/\gamma_1 = 0.444521$

Step 4. Domain conversion

Converting one domain-time period back to a system-time ratio: the phase turns once each time $x$ grows by a factor $e^{2\pi/\gamma}$ -- 1.559743 for the first zero, 1.348355 for the second, 1.285591 for the third. In linear time the periods lengthen; in domain time they are evenly spaced. The fluctuation of the primes, irregular in system time, becomes a sum of fixed frequencies in domain time.

Step 5. Finding

Verdict: Hypothesis. Discrimination: if the reading "domain time = log of system time" (D-143; the WKB logarithmic structure of Paper II prediction 2) is rejected elsewhere, this card falls with it. The explicit formula itself is a mathematical identity and carries no independent falsification condition.
