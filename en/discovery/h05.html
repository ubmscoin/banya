H-05: neutrino = Compare-skipped particle

The neutrino is a particle in which the Compare stage of CAS is skipped. When Compare is skipped, mass is suppressed by α³ and becomes extremely light. Prediction for the neutrino mass sum: Σm_ν = 58.5 meV.

In δ² = (t+s)² + (o+sp)², if the OPERATOR (o+sp) skips Compare, the observer branch (Axiom 7: true ==> juim, false ==> retain) does not execute. juim is weakened, so the mass written into DATA is suppressed by α³ ≈ 2.4×10⁻¹².

Axiom 7 (write = juim, with Compare as the branching agent) ==> Axiom 4 (cost: the Compare cost +1 is not paid) ==> Axiom 5 (TOCTOU lock). Skipping Compare = the lock is not acquired. Executing Swap without the lock attenuates the determining power of juim by α³. 3 = number of CAS stages, one suppression each at R, C and S.

A Compare-skipped particle participates in SU(2) interactions only via its left-handed component (linked to H-31). Without Compare, the observer branch flows in only one direction (true). This is the chirality structure of the neutrino.

Σm_ν = 58.5 meV. This is consistent with the Normal Ordering of masses (H-25). Individual masses: m₁ ≈ 0, m₂ ≈ 8.6 meV, m₃ ≈ 49.9 meV (assuming NO).

Compatible with the Planck cosmological upper bound Σm_ν < 120 meV; also compatible with the recent DESI BAO result Σm_ν < 72 meV. 58.5 meV lies within every current experimental constraint.

In the Standard Model, neutrino mass is an input parameter. The seesaw mechanism postulates heavy right-handed neutrinos. In the Banya Framework, the mass suppression is derived from the CAS structure of "Compare skipped".

The seesaw mechanism requires new particles at the GUT scale (10¹⁴ GeV). The Banya Framework achieves the same effect via internal CAS-path omission. No new particles needed.

The KATRIN experiment (around 2027) will push the neutrino-mass upper bound below 0.2 eV. JUNO will discriminate NO/IO. 58.5 meV is clearly different from the minimum value (~100 meV) emerging in IO, so if IO is established, this hypothesis is rejected.
