Core Finding

P-79: 7-qubit Logical Error Floor $=\alpha^2$

$$\text{7-qubit (Steane) logical error-rate floor}=\alpha^2\sim5.3\times10^{-5}\quad(\text{Compare cost 2 times})$$

Prediction: 7-qubit (Steane) code logical error floor $\alpha^2\sim5.3\times10^{-5}$. Test: IBM/Google 7-qubit QEC (2027~).

In the Banya formula $\delta^2=(\text{time}+\text{space})^2+(\text{observer}+\text{superposition})^2$, the single-gate error floor is the CAS Compare selection cost $\alpha$ (P-19, P-43).

The 7-qubit Steane code (the QEC minimum, P-66) protects one logical qubit, and a logical error requires two Compare costs to coincide.

So the 7-qubit logical error floor is the square of the single cost, $\alpha^2\sim5.3\times10^{-5}$ ==> the code suppresses the physical-gate floor $\alpha$ to $\alpha^2$.

This shows that the core of error correction — squaring the physical error rate $\alpha$ into a logical error rate $\alpha^2$ — arises directly from the CAS cost structure.

$\alpha^2=(1/137)^2\approx5.3\times10^{-5}$, two orders below the single-gate 0.73%.

So this prediction is not "QEC reduces errors" but the quantitative claim "the 7-qubit logical floor is exactly $\alpha^2$, below which is impossible."

Lowering the logical error rate below $\alpha^2$ requires a larger code (increased distance); with a single 7-qubit code, $\alpha^2$ is the floor.

This is in the same QEC family as P-19 (gate floor α), P-66 (QEC minimum 7), and P-94 (threshold 1/35).

5-Step Recursive Substitution: Deriving the 7-qubit Logical Floor $\alpha^2$ from the Two-Compare Overlap Cost

Step 1. Banya Formula

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

The 7-qubit logical error floor is the two-Compare cost: a logical error occurs only when the single-gate cost $\alpha$ overlaps twice. This overlap cost is read using the fact that the full-description DOF 7 (Axiom 9) is isomorphic to the 7-qubit Steane code (QEC minimum, P-66) and that the single-gate floor is $\alpha$ (P-19).

Step 2. Norm Substitution

The norm being substituted is the code-distance norm that counts how many Compare-cost overlaps are required before a logical error occurs. This norm is chosen because the single 7-qubit code protects one logical qubit and a logical error requires two Compare costs to overlap. The logical error floor is therefore substituted by the square of the single cost $\alpha$.

$p_{\text{phys}} = \alpha$
$p_{\text{logical}}^{\text{floor}} = \alpha^2$
$p_{\text{phys}}$: physical gate error floor = $\alpha$ (P-19) | $p_{\text{logical}}^{\text{floor}}$: 7-qubit logical error floor | $2$: number of Compare overlaps for a logical error | $7$: Steane-code qubits = full-description DOF (Axiom 9)
