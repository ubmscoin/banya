Derives a candidate formula for the pion mass $m_\pi$ from the CAS domain exchange count and the complete CAS path count.

$m_\pi \propto 4\alpha/21$. $4$ = number of domains that Swap exchanges (the 4 axes of Axiom 1). $21 = 7 \times 3$ = CAS state count (7) × CAS stages (3) = number of complete CAS paths. $\alpha$ = bracket-crossing cost.

Axiom 1 (4 domain axes) supplies Swap(4). Axiom 2 (CAS data type 7) and Axiom 3 (CAS 3 stages) supply $21$. Axiom 4 (cost: +1 per axis) lets $\alpha$ set the scale.

When CAS exchanges 4 domains through 21 paths, the bracket cost $\alpha$ multiplies in to set the mass scale. This is the structure of the lightest hadron, on which juim is not locked.

$\sigma \times M_Z = 127\;\text{MeV}$, experimental value $135\;\text{MeV}$. Error $6.1\%$. C-grade; NLO corrections required.

The pion is the lightest hadron and the pseudo-Goldstone boson of chiral symmetry. It mediates the nuclear force.

In the Standard Model $m_\pi$ is computed by chiral perturbation theory from quark masses and the QCD scale, whereas the Banya Framework sets the scale from CAS path count and bracket cost alone.
