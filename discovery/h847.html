H-847. 메모리 = DATA 이산 저장의 CAS 읽기/쓰기

핵심 발견

H-847: 메모리 = DATA 이산 저장의 CAS 읽기/쓰기

$$\text{DATA}[addr] \xrightarrow{\text{CAS read}} \text{output} \;;\quad \text{input} \xrightarrow{\text{CAS write}} \text{DATA}[addr]$$

등급: B

메모리는 DATA를 이산 주소에 저장하고 CAS를 통해 읽기/쓰기하는 장치이다. 각 메모리 셀 = DATA 단위 저장소. 주소 = ECS 좌표. 읽기 = CAS Compare 후 DATA 복사. 쓰기 = CAS Swap으로 DATA 덮어쓰기.

공리 4(DATA 이산), 공리 5(CAS 읽기/쓰기), 공리 2(ECS 주소 격자)

공리 4: DATA는 이산 단위로 저장된다. 1비트 = 최소 DATA 단위. 바이트/워드 = DATA 묶음. 공리 5: CAS Compare = 읽기(DATA 비파괴 복사), CAS Swap = 쓰기(DATA 갱신). 공리 2: ECS 격자가 주소 공간을 제공. 물리 주소 = ECS 좌표.

DRAM: 커패시터 전하 = DATA 저장. 주기적 리프레시 필요(CAS 반복). SRAM: 래치 = 안정 DATA 저장. 리프레시 불필요. Flash: 부유 게이트 전하 = 비휘발 DATA. HDD/SSD: 자기/전하 = 대용량 DATA.

DRAM: $\sim 16$~$64\;\text{GB}$. 접근 시간: $\sim 10\;\text{ns}$. SSD: $\sim\;\text{TB}$. 접근 시간: $\sim\;\mu\text{s}$. 레지스터: $\sim\;\text{ps}$ 접근.

메모리 계층 구조 지연시간 비율 이론과 실측 정합.

DRAM, SRAM, Flash, 메모리 계층, 폰 노이만 아키텍처

컴퓨터 메모리 기술 70년 이상의 실증.

CAS 읽기/쓰기 최소 에너지의 란다우어 한계 연결.

재대입 용도: 재대입 용도: H-845(집적회로). H-844(트랜지스터). H-862(광통신)

가설에서 멈춘 이유: 본 카드는 가설(분류 III)로 분류되어 다음 라운드로 미진행한 채 멈춰 있다. 정량 식과 실험값이 둘 다 있지만 forward chain의 마지막 단계가 닫히지 않았다. 식의 모든 계수가 공리 또는 1차 정수에서 직접 도출되지 않고 일부가 외부 입력 또는 가설로 남았다. 잔여 과제 명시: 재대입 용도: 재대입 용도: H-845(집적회로). H-844(트랜지스터). H-862(광통신) D 승격 경로는 (1) 위 잔여 과제 해소, (2) 라이브러리의 인접 D/H 카드를 재귀 대입 라운드 입력으로 재투입, (3) 공리 1, 공리 2, 공리 4, 공리 9, 공리 11 명제 중 미적용 명제 추가 도입의 3가지가 표준.

왜 이 판정인가

판정: 가설 -- Hypothesis (재귀 대입 진행 중)

이유: 재귀 입력 3개 확인, 다음 라운드 진행 시 D 승격 가능 / 잔여 과제 명시

위치: 카테고리: h misc. 도메인: delta ==> 자연 분류 외 (도메인 미확정, 후속 정련 필요). 재귀 대입 경로: H-844, H-845, H-862

5단계 재귀 대입: CAS 읽기/쓰기 비대칭 비용에서 메모리 접근 구조 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

메모리는 DATA를 이산 단위로 보관하고 CAS가 그 자리를 읽고 쓰는 장치다. 반야식 우항의 space 항이 DATA가 놓이는 자리(주소)를 주고, observer 항이 그 자리를 지정해 접근하는 비용을 준다. 읽기와 쓰기는 같은 자리에 대한 두 방향의 CAS 연산이다.

2단계. 노름 치환

(a) 치환하는 노름은 CAS 읽기/쓰기 비대칭 노름이다. 읽기는 Compare가 DATA를 비파괴로 복사하는 가역 연산이고(공리 5: Compare), 쓰기는 Swap이 기존 DATA를 덮어쓰는 비가역 연산이다(공리 5: Swap). (b) 이 노름을 택하는 까닭은 메모리의 한 자리에 대한 두 연산의 비용 차이가 메모리 계층(레지스터·DRAM·SSD)의 접근 시간 차이를 정하기 때문이다. 주소는 ECS 격자 좌표(공리 2)이고, 1비트는 이산 DATA의 최소 단위다(공리 4). 왜 이 노름인가 — 메모리 접근 구조 자체가 CAS 읽기/쓰기 비대칭 비용에서 비롯하므로, 이 비용 구조를 그대로 담는 노름이라야 군더더기 없이 대응되기 때문이다. 왜 이 치환이 정당한가 — 좌변의 표준 물리식과 우변의 반야식이 같은 양을 가리키되 반야식은 그 양을 CAS 비용 항으로 다시 쓴 것이므로, 두 변은 같은 물리량의 두 표현이기 때문이다.

$\text{read}:\ \text{out} = \text{Compare}(\text{DATA}[a])$
$\text{write}:\ \text{DATA}[a] = \text{Swap}(\text{in})$
$a$: ECS 격자 주소 좌표 | $\text{DATA}[a]$: 자리 $a$의 이산 DATA | Compare: 비파괴 읽기 (가역) | Swap: 덮어쓰기 (비가역) | out/in: 출력/입력 DATA

3단계. 상수 대입

이 단계에서는 앞의 반야 치환식에 등장한 기호에 실제 상수값을 대입한다. 대입하는 값은 모두 선행 D/H/P 카드나 공리에서 이미 고정된 상수이며, 본 카드에서 새로 정한 값이 아니다. 왜 이 상수들인가 — 메모리 접근 구조 산출에 필요한 입력이 이들로 모두 닫히고, 그 밖에 손으로 맞춘 자유 매개변수가 하나도 없기 때문이다. 각 값은 측정 또는 선행 도출에서 온 것이므로 도출의 객관성이 보장되고 순환 논증이 끼어들 여지가 없다. 아래에 각 상수의 값과 그 출처(카드·공리)를 정리한다.

레지스터 접근 = $\sim$ ps CPU 레지스터 실측
DRAM 접근 = $\sim$ 10 ns DDR 실측
SSD 접근 = $\sim$ us NAND Flash 실측
DRAM 용량 = 16 $\sim$ 64 GB 소비자 시스템
1 bit = 최소 이산 DATA 단위 공리 4

4단계. 도메인 변환

(a) 이산 저장 접근 도메인(ECS 격자 위 CAS 읽기/쓰기)으로 변환한다. (b) 이 변환으로 보려는 것은 자리 지정 후 읽기/쓰기 한 번에 드는 접근 시간이 계층마다 어떻게 갈리는가다. 레지스터에서 SSD까지 접근 시간이 약 $10^6$배 벌어지는 계층이 그 답이다. 왜 이 도메인으로 변환하는가 — 메모리 접근 구조 자체가 이 도메인에서 측정되는 관측량이므로, 비용 구조를 이 도메인으로 사영해야 실험값과 직접 견줄 수 있기 때문이다. 왜 이 변환이 도출을 닫는가 — 앞에서 대입한 상수만으로 우변이 완전히 수치화되어 외부 입력 없이 좌변 관측량이 결정되기 때문이다.

$\dfrac{t_{\text{SSD}}}{t_{\text{reg}}} \approx \dfrac{10^{-6}}{10^{-12}} = 10^{6}$

5단계. 발견

도출 구조: 읽기 = Compare(가역), 쓰기 = Swap(비가역)

이 단계는 도출값을 측정값과 대조해 판정한다. 도출값과 측정값의 정합 정도가 판정의 직접 근거다. 왜 이 판정인가 — forward chain이 공리와 실재 카드 입력만으로 닫혔는지, 그리고 오차가 승급 기준 안에 드는지에 따라 발견·가설·예측이 갈리기 때문이다. 이 도출은 표준 이론의 사후 맞춤이 아니라 CAS 비용 구조에서 앞으로 전개된 결과다. 측정 정밀도가 높아지거나 후속 카드가 재투입되면 이 판정은 재검토된다.

측정 정합: 접근 시간 ps(레지스터) ~ ns(DRAM) ~ us(SSD)
측정 검증 대기: CAS 쓰기 최소 에너지의 란다우어 한계 도출

판정: 가설. 읽기/쓰기의 가역·비가역 비대칭이 메모리 계층 접근 시간을 정성적으로 닫지만, 쓰기 비용의 란다우어 한계 정량 도출이 미완이라 발견 승격 전 단계다.

읽기는 가역 Compare, 쓰기는 비가역 Swap이라는 비대칭이 메모리 계층 전체를 한 규칙으로 묶는다.
