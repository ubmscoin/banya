H-515. 펜타쿼크 = 5-CAS 번들의 FSM 결합

핵심 발견

H-515: 펜타쿼크 = 5-CAS 번들의 FSM 결합

$$P_c = qqqq\bar{q},\quad \text{5-CAS 번들}:\; \text{FSM 닫힘 유지}$$

등급: C

펜타쿼크($qqqq\bar{q}$)는 5개 쿼크/반쿼크가 색 싱글렛을 형성하는 이국적 하드론이며, 5개 CAS 번들이 FSM 닫힘 조건을 만족하는 결합이다. LHCb(2015)에서 $P_c(4380)$, $P_c(4450)$ 발견. 이들은 FSM 조합 규칙(H-501)의 비표준 모드이다.

공리 12(FSM 닫힘 = 색 싱글렛), 공리 14(FSM 노름 = 질량), H-501(스펙트럼 조합)

공리 12(FSM 닫힘: $qqqq\bar{q}$도 색 싱글렛 가능 ==> 허용), 공리 14(5-쿼크 FSM 노름 합 ==> 질량 $\sim 4{-}5\;\text{GeV}$), 공리 4(CAS 비용 ==> 결합 에너지: 높은 CAS 비용 ==> 불안정), 공리 2(CAS 5중 결합 구조)

펜타쿼크는 분자형($\bar{D}^{(*)}\Sigma_c^{(*)}$) 또는 컴팩트 5-쿼크로 해석 가능. FSM 관점: 두 FSM 닫힌 클러스터의 약한 결합(분자) vs 하나의 5-FSM 닫힌 영역(컴팩트). 높은 CAS 비용 ==> 넓은 폭(불안정).

$P_c(4312)$, $P_c(4440)$, $P_c(4457)$ (LHCb 2019). 폭 $\Gamma \sim 10{-}200\;\text{MeV}$.

LHCb 발견 확인. 질량은 $\bar{D}^{(*)}\Sigma_c^{(*)}$ 문턱 근처 ==> 분자형 지지.

펜타쿼크(LHCb 2015/2019), 이국적 하드론, 하드론 분자, 매력 바리온

LHCb/Belle II에서 추가 펜타쿼크 탐색. 바닥 쿼크 펜타쿼크 예측.

분자 vs 컴팩트 구분의 FSM 판별. 비매력 펜타쿼크(경쿼크만) 가능성. 결합 메커니즘 정량화.

재대입 용도: 재대입 용도: H-501(스펙트럼) 이국적 확장. H-516(이국적 하드론) 분류. H-504(안정성) 불안정 모드.

5단계 재귀 대입: 5-CAS 번들 FSM 노름에서 펜타쿼크 질량 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

펜타쿼크는 쿼크 4개와 반쿼크 1개가 색 싱글렛을 이루는 5-CAS 번들이다. FSM이 닫힌 상태를 색 싱글렛으로 허용하므로(공리 12) $qqqq\bar{q}$도 닫힘 조건을 만족한다. 닫힌 FSM의 노름 합이 질량이 되고(공리 14), 높은 CAS 비용이 넓은 폭으로 나타난다(공리 4).

2단계. 노름 치환

치환하는 노름은 5-CAS 번들의 FSM 노름 합이다. 분자형 해석에서 펜타쿼크가 두 닫힌 클러스터 $\bar{D}$ 메손과 $\Sigma_c$ 바리온의 약한 결합으로 닫히기 때문에 이 노름을 택한다. 따라서 펜타쿼크 질량을 두 하드론 노름의 합으로 치환한다.

$P_c = qqqq\bar{q}$ (5-CAS 번들, FSM 닫힘 유지)
$M_{P_c} \approx M_{\bar{D}} + M_{\Sigma_c}$
$M_{P_c}$: 펜타쿼크 질량 | $M_{\bar{D}}$: $\bar{D}$ 메손 노름 | $M_{\Sigma_c}$: $\Sigma_c$ 바리온 노름 | FSM 닫힘: 색 싱글렛 (공리 12·공리 14)

3단계. 상수 대입

M_D     = 1.869 GeV            PDG 2024
M_Sigma = 2.453 GeV            Sigma_c(2455)
문턱    = M_D + M_Sigma        분자형 결합 한계

4단계. 도메인 변환

강력 ring-7 결합 도메인으로 변환한다. 이 변환으로 보려는 것은 5-CAS 번들이 닫힐 때의 질량, 곧 $\bar{D}\Sigma_c$ 문턱 근처 값이다. 두 하드론 노름을 더해 그 값을 산출한다.

$M_{P_c} \approx 1.869 + 2.453 = 4.322\ \text{GeV}$

5단계. 발견

도출: $M_{P_c} \approx 4.32\ \text{GeV}$ ($\bar{D}\Sigma_c$ 문턱)
측정: $P_c(4312)$ (LHCb 2019), 폭 $\Gamma \sim 10\text{--}200\ \text{MeV}$
오차: $\sim 0.2\%$

판정: 가설. $\bar{D}\Sigma_c$ 문턱 질량은 분자형 해석을 지지하며 0.2%로 닫히나, 결합 에너지와 폭 $\Gamma$의 정량이 공리에서 직접 도출되지 않아 forward chain 마지막 단계가 미완이다.
