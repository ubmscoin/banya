H-608. 란다우어-베넷 가역 계산 = Compare만의 비용 0 연산

핵심 발견

H-608: 란다우어-베넷 가역 계산 = Compare만의 비용 0 연산

$$\text{가역 계산: Swap 없음} \;\Rightarrow\; \text{비용} = 0,\quad \text{비가역: Swap 포함} \;\Rightarrow\; \text{비용} \geq k_BT\ln 2$$

등급: B

가역 계산(Swap 없이 Compare만)은 CAS 비용 0이다. 비가역 계산(Swap 포함)은 최소 $k_BT\ln 2$의 비용을 소산한다. 베넷의 가역 계산 = CAS에서 Swap을 회피하는 경로.

공리 2(CAS Read==>Compare==>Swap), 공리 4(비용)

공리 2(Compare = 가역, Swap = 비가역), 공리 4(Swap 비용 = $+1$ = 열 소산), 공리 6(RLU 감쇠 = 열)

가역 컴퓨터 = Compare 전용 CAS. 비가역 소거 = Swap 실행. 맥스웰 도깨비 = Compare만 수행하는 관측자(비용 0이지만 기록에 Swap 필요).

가역 계산 에너지 하한 = 0. 비가역 1비트 소거 = $k_BT\ln 2$.

란다우어-베넷 이론과 일치. 실험 검증됨(2012 Bérut et al.).

란다우어 원리(1961), 베넷 가역 계산(1973), 맥스웰 도깨비

가역 계산의 에너지 0 실현 실험(열 잡음 내) 검증.

완전 가역 CAS 컴퓨터의 구현 가능성 분석.

5단계 재귀 대입: CAS Swap 비용에서 가역 계산 0 비용 하한 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

한 연산의 비용은 CAS가 Swap을 실행하는지 여부에서 갈린다. Read와 Compare는 상태를 바꾸지 않는 가역 단계이고, Swap만이 + 순서를 횡단하며 비용 $+1$을 발생시킨다(공리 2, 공리 4). Swap을 회피하면 비용 0, 실행하면 열로 소산된다(공리 6).

2단계. 노름 치환

(a) 치환하는 노름은 Swap 비가역 노름이다. Compare 전용 경로는 가역이라 비용 0, Swap을 포함한 경로는 비가역이라 1비트당 $k_BT\ln 2$의 하한을 갖는다. (b) 가역 계산이 곧 Swap을 빼고 Compare만 도는 CAS이고 비가역 소거가 곧 Swap 실행이므로, Swap 유무가 비용 하한을 가른다 — 이 때문에 이 노름을 택한다. 따라서 계산 비용을 Swap 비가역 노름으로 치환한다.

$\text{Compare}\ \text{only}:\ E = 0$
$\text{Swap}\ \text{included}:\ E \geq k_BT\ln 2$
$E$: 연산당 최소 비용 | Compare only: Swap 없는 가역 경로 | Swap: 비가역 쓰기 ($+1$ 비용) | $k_BT\ln 2$: 1비트 소거 하한

3단계. 상수 대입

$k_{B}$ = $1.380649\times10^{-23}$ J/K CODATA 2018
T = 300 K 상온
$\ln$ 2 = 0.693147
$E_{rev}$ = 0 Swap 없음 (Compare 전용)
$E_{irr}$ = $k_{B}$ * T * $\ln$ 2 Swap 1회 (1비트 소거)

4단계. 도메인 변환

(a) 계산 비용 도메인(Compare 분기: true에서 Swap을 거쳐 DATA, false에서 중첩 유지)으로 변환한다. (b) 보려는 것은 Swap 유무에 따라 갈리는 연산당 비용 하한이다. 가역 경로와 비가역 1비트 소거에 각각 대입해 값을 산출한다.

$E_{\text{rev}} = 0,\quad E_{\text{irr}} = 1.380649\times 10^{-23} \times 300 \times 0.693147 = 2.871\times 10^{-21}\ \text{J}$

5단계. 발견

도출값: $E_{\text{rev}} = 0,\ E_{\text{irr}} = 2.871\times 10^{-21}\ \text{J}$ (300K)
측정값: 비가역 소거 $k_BT\ln 2$ (Bérut 2012)
오차: $0.0\%$

판정: 가설. Swap 비가역 하한은 노름으로 닫히지만, 완전 가역 CAS 컴퓨터가 열 잡음 내에서 비용 0을 실현하는 마지막 단계가 미완이다.

맥스웰 도깨비는 Compare만 수행해 비용 0이지만, 그 기록을 지우는 순간 Swap이 강제되어 $k_BT\ln 2$를 치른다.
