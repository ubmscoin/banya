1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

프랙탈은 δ 자기참조 루프(공리 15: δ가 observer·Compare·DATA를 거쳐 다시 δ로 닫히는 순환)가 같은 비용 사상을 스케일마다 반복할 때 창발하는 구조다. RLU 감쇠(공리 6)의 스케일 불변 영역에서 비용이 멱법칙(공리 4)으로 분포한다.

2단계. 노름 치환

치환하는 노름은 자기참조 복잡도 노름이다. 한 번의 자기참조 반복이 척도를 $r$배 줄이면서 닮은 조각 $n$개를 만들고, 이 $(n, r)$ 쌍이 스케일 불변 채움 차원을 정하기 때문에 이 노름을 택한다. 따라서 박스 카운트 척도-개수 관계를 자기참조 복잡도 지수로 치환한다.

$N(r) = r^{-D_f}$
$D_f = \dfrac{\ln n}{\ln(1/r)}$
$D_f$: 하우스도르프 차원 = 자기참조 복잡도 지수 | $n$: 한 반복의 닮은 조각 수 | $r$: 척도 축소비 | $N(r)$: 척도 $r$의 덮개 수

3단계. 상수 대입

self-ref = 1회 반복 = $\delta$ 루프 1주기 공리 15
Koch n=4, r=1/3 $D_{f}$ = $\ln4/\ln3$ = 1.262
Mandelbrot 경계 $D_{f}$ = 2

4단계. 도메인 변환

정보·의식 도메인(δ 자기참조 루프)으로 변환한다. 이 변환으로 보려는 것은 자기참조 반복이 채우는 스케일 불변 차원 $D_f$다. 코흐 곡선은 한 반복이 닮은 조각 4개를 $1/3$ 척도로 만들어 $D_f = \ln 4/\ln 3$을 준다.

$D_f = \dfrac{\ln 4}{\ln 3} = 1.2619$

5단계. 발견

도출: $D_f = \ln n/\ln(1/r)$ = 자기참조 복잡도 지수
대조: 코흐 $D_f = 1.262$, 만델브로 경계 $D_f = 2$
