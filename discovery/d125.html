D-125: $\alpha_s(M_Z)$ running = 0.1179 — S급

$$\alpha_s(M_Z) = \frac{\alpha_s(\Lambda)}{1 + b_0 \alpha_s(\Lambda)\ln(M_Z^2/\Lambda^2)} = 0.1179$$

등급 S급 · 정확 일치

D-03 + D-44(β₀=7) 체인으로 M_Z 스케일까지 running. 실험값 0.1179±0.0009. 반야식: α_s(M_Z) = α_s(Λ) / [1 + b₀·α_s(Λ)·ln(M_Z²/Λ²)]. CAS 비용의 스케일 의존성. 치환: α_s(Λ)(D-03) = 출발점. b₀ = β₀/(2π)(D-44). M_Z(D-22) = 도착 스케일. 쥐다(juida)의 에너지 의존 비용. 공리 체인: 공리 3(CAS) ==> D-03(Λ_QCD) ==> D-44(β₀=7) ==> D-22(M_Z) ==> running 도출. 도출: d-ring 위 CAS 비용은 에너지 스케일에 따라 로그적으로 변화. 링 이음새 간격이 스케일에 비례하여 넓어진다. 수치: α_s(M_Z) = 0.1179. 실험값 0.1179 ± 0.0009. 오차: 중심값 정확 일치. 2-loop 보정 포함 시 불확도 범위 내. 물리 대응: 강결합상수의 에너지 의존성(running). QCD의 점근적 자유 현상. 검증: D-03(Λ_QCD)과 D-44(β₀) 입력 정밀도 확인. 실험값 불확도 범위 내. 재대입: LHC 물리, 제트 생성 단면적 등 고에너지 QCD 계산의 핵심 입력.

5단계 재귀 대입: CAS 비용의 스케일 의존성에서 $\alpha_s(M_Z)$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

강결합은 CAS가 색 자료형을 쥐는 ring-7 비용이며, 이 비용은 에너지 스케일에 따라 로그적으로 변한다. CAS 사이클이 반복될수록 링 이음새 간격이 스케일에 비례해 넓어지는 것이 $\delta^2$ 비용의 running이다(공리 3 비가역 연산).

2단계. 노름 치환

(a) 치환하는 노름은 ring-7 강결합 노름의 1-loop running 노름이다. (b) 고정된 결합이 아니라 스케일을 횡단하며 변하는 비용을 보려 하기 때문에 이 노름을 택한다. 베타 함수 계수 $\beta_0 = 7$(D-44)이 running을 지배하고, $\Lambda$ 스케일 결합(D-03)을 $M_Z$(D-22)까지 흘려보낸다.

$\alpha_s(Q^2) = \dfrac{\alpha_s(\mu^2)}{1 + b_0\,\alpha_s(\mu^2)\ln(Q^2/\mu^2)}$
$\alpha_s(M_Z) = \dfrac{\alpha_s(\Lambda)}{1 + b_0\,\alpha_s(\Lambda)\ln(M_Z^2/\Lambda^2)}$
$\alpha_s$: 강결합상수 | $b_0 = \beta_0/(2\pi)$: 1-loop 계수 | $\beta_0 = 7$: 강력 자료형 (D-44) | $\Lambda$: QCD 스케일 (D-03) | $M_Z$: Z 보존 질량 (D-22)

3단계. 상수 대입

$\beta_{0}$ = 7 D-44
$b_{0}$ = 7/(2 $\pi$) = 1.1141
$M_{Z}$ = 91.1876 $\text{GeV}$ D-22
$\alpha_{s}$ = 0.1179 ${\pm}$ 0.0009 PDG 2024 ($M_{Z}$ 스케일)

4단계. 도메인 변환

(a) 강력 ring-7 결합 도메인을 $M_Z$ 스케일로 변환한다. (b) 보려는 것은 전약 통합 스케일에서 측정되는 강결합의 running 값 $\alpha_s(M_Z)$다. $\beta_0 = 7$의 양수 부호가 점근적 자유를 보장하면서 결합을 $M_Z$로 흘려보낸다.

$\alpha_s(M_Z) = \dfrac{\alpha_s(\Lambda)}{1 + b_0\,\alpha_s(\Lambda)\ln(M_Z^2/\Lambda^2)} = 0.1179$

5단계. 발견

오차: 중심값 정확 일치
