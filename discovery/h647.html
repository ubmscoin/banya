H-647. 핵융합 = FSM 결합의 비용 이득

핵심 발견

H-647: 핵융합 = FSM 결합의 비용 이득

$$4p \to {}^4\text{He} + 2e^+ + 2\nu_e + 26.7\;\text{MeV} \;\leftrightarrow\; \text{FSM 결합 비용 이득}$$

등급: B

핵융합은 가벼운 핵이 결합하여 더 무거운 핵을 만들 때 결합 에너지 차이만큼 에너지를 방출하는 과정이다. 반야에서 낮은 FSM 노름 핵자들이 결합하면 핵자당 비용이 감소하여 잉여 비용이 방출된다.

공리 3(FSM 결합), 공리 4(비용 이득), H-643(결합 에너지)

공리 3(FSM 결합 = 노름 합산), 공리 4(비용 최소화 ==> Fe-56까지 결합 이득), 공리 6(RLU HOT = 쿨롱 장벽 극복 온도). pp-체인: 4H ==> He + 26.7 MeV. CNO 순환: 촉매 FSM을 통한 간접 결합.

쿨롱 장벽 = CAS 전자기 비용 장벽. 가모프 피크 = 열에너지와 터널링 확률의 교차. Fe-56 이후 결합 비용 이득 소멸 ==> 융합 종료. 별의 양파 껍질 구조 = 순차적 FSM 노름 증가.

pp-체인: $26.7\;\text{MeV}$/반응. 태양 중심 온도: $1.57 \times 10^7\;\text{K}$. 가모프 피크 에너지 $\sim 6\;\text{keV}$.

태양 광도 $L_\odot = 3.828 \times 10^{26}\;\text{W}$와 pp-체인 계산 정합.

핵융합, pp-체인, CNO 순환, 가모프 피크, 쿨롱 장벽

태양 중성미자 검출(SNO, Super-K)로 pp-체인 확인됨.

FSM 비용에서 가모프 피크 에너지의 정량 도출.

재대입 용도: 재대입 용도: H-667(별 에너지원). H-669(주계열성). H-674(초신성)

5단계 재귀 대입: FSM 결합 비용 이득에서 pp-체인 $26.7\;\text{MeV}$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

핵융합은 낮은 FSM 노름 핵자들이 결합하며 핵자당 비용이 줄어 잉여 비용이 해방되는 사건이다. FSM 결합(공리 3)에서 비용 최소화(공리 4)가 Fe-56까지 결합을 끌고 가고, 쿨롱 장벽 극복은 RLU HOT 온도(공리 6)로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 핵자당 결합 비용을 합산하는 FSM 노름 합산 비용이다. (b) 핵융합이 네 양성자를 한 닫힌 FSM(He-4)으로 묶는 결합 사건이고, 묶음의 이득이 노름 합산 차이로 정해지기 때문에(공리 3) 이 노름을 택한다. 해방 비용은 입력 4양성자 질량 비용에서 출력 He-4 질량 비용을 뺀 차이로 닫힌다.

$Q = (4m_p - m_{^4\text{He}})c^2$
$4p \;\Rightarrow\; {}^4\text{He} + 2e^+ + 2\nu_e + Q,\quad Q = 26.7\;\text{MeV}$
$Q$: 결합 비용 이득 | $m_p$: 양성자 질량 비용 | $m_{^4\text{He}}$: He-4 질량 비용 | $2e^+$: 베타 플러스 출력 | $2\nu_e$: 중성미자 출력

3단계. 상수 대입

Q_pp     = 26.7 MeV         pp-체인 해방 비용
T_core   = 1.57e7 K         태양 중심 온도
E_Gamow  = 6 keV            가모프 피크 에너지
L_sun    = 3.828e26 W       태양 광도

4단계. 도메인 변환

(a) 항성 핵 결합 비용 도메인(쿨롱 장벽 + 터널링)으로 변환한다. (b) 이 변환으로 보려는 것은 4양성자가 He-4로 묶일 때 해방되는 결합 비용 $Q$다. 질량 비용 차이를 합산해 그 값을 산출한다.

$Q = (4m_p - m_{^4\text{He}})c^2 = 26.7\;\text{MeV}$

5단계. 발견

도출값: $Q = 26.7\;\text{MeV}$ (pp-체인)
측정값: 태양 광도 $L_\odot = 3.828\times 10^{26}\;\text{W}$, 가모프 피크 $\approx 6\;\text{keV}$
정합: pp-체인 계산과 태양 광도 정합

판정: 가설. 결합 비용 이득 $26.7\;\text{MeV}$가 노름 합산 차이로 닫히나, 가모프 피크 에너지의 정량 도출이 남아 forward chain 마지막 단계가 미완이다.
