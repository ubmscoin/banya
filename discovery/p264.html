P-264. 측정 후 상태 순도 회복 = Compare true 확률 제곱

핵심 발견

P-264: 측정 후 상태 순도 회복 = Compare true 확률 제곱

$$\text{Tr}(\rho_{\text{post}}^2)=\sum_k p_k^2,\quad p_k=\Pr(\text{Compare true}_k)\;(\text{붕괴 가중 제곱합})$$

예측: 사영 측정 후 비선택 상태의 순도는 각 결과의 Compare-true 확률 제곱합과 정확히 같으며, 최대 혼합($p_k=1/d$ 균등)에서 순도는 정확히 1/d로 바닥친다. (finding-precision: 정확)

반야식 $\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$에서 사영 측정 후 축소 상태의 순도는 Compare true 시 Swap 붕괴 비용에서 도출된다 (공리 2, 공리 7, 공리 13, 공리 1).

H-447(붕괴=$Swap){\cdot}H-13($붕괴=쓰기)는 정성이다. Compare 분기 확률의 제곱합이 순도로 닫히고 균등시 1/d로 바닥치므로 예측이다.

(a)Compare 분기 확률 노름 (b)각 분기 확률 제곱합 = 밀도행렬 순도.

검증: 큐딧 비선택 측정 후 상태 단층촬영으로 순도가 $\Sigma$ $p_k^{2}$와 일치하고 균등시 1/d인지 확인.

반박: 비선택 측정 후 순도가 $\Sigma$ $p_k^{2}$와 다르거나 균등시 1/d 아니면 반증.

재대입 용도: 검증: 큐딧 비선택 측정 후 상태 단층촬영으로 순도가 $\Sigma$ $p_k^{2}$와 일치하고 균등시 1/d인지 확인. 반박: 비선택 측정 후 순도가 $\Sigma$ $p_k^{2}$와 다르거나 균등시 1/d 아니면 반증. 출처: 공리 2, 공리 7, 공리 13, 공리 1.

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

사영 측정 후 축소 상태의 순도는 Compare true 시 Swap 붕괴 비용에서 도출된다. 관련 공리: 공리 2, 공리 7, 공리 13, 공리 1.

2단계. 노름 치환

(a)Compare 분기 확률 노름 (b)각 분기 확률 제곱합 = 밀도행렬 순도.

$\text{Tr}(\rho^2)=\sum_k p_k^2,\;\; p_k=\langle k|\rho|k\rangle$
$\text{Tr}(\rho_{\text{post}}^2)=\sum_k \Pr(\text{Compare true}_k)^2$
$\rho_{\text{post}}$: 측정 후 축소 상태 | $p_k$: 결과 k의 Compare true 확률 (공리 2) | $d$: 측정 기저 차원 | 균등 $p_k=1/d$ = 최대 혼합

3단계. 상수 대입

$\sum_k p_k = 1$ (정규화)
$p_k = \Pr(\text{Compare true}_k)$ (공리 2)
균등 = 1/d

4단계. 도메인 변환

(a)측정 붕괴 도메인 (b)측정이 순수 상태를 얼마나 혼합시키는가 본다.

$\text{Tr}(\rho_{\text{post}}^2)=\sum_k p_k^2\geq\frac{1}{d}\;(\text{균등에서 등호})$

5단계. 예측

예측값: $\text{Tr}(\rho_{\text{post}}^2)_{\min}=\frac{1}{d}\;(\text{균등 측정, exact})$

판정: 예측. 비선택 측정 후 순도가 $\Sigma$ $p_k^{2}$와 다르거나 균등시 1/d 아니면 반증.
