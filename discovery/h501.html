H-501. 하드론 스펙트럼 = FSM 노름 조합 규칙

핵심 발견

H-501: 하드론 스펙트럼 = FSM 노름 조합 규칙

$$M_{\text{hadron}} = \sum_i \|\text{FSM}_i\| + V_{\text{CAS}}(\{r_{ij}\}),\quad \text{FSM 조합} \in \{q\bar{q},\; qqq\}$$

등급: B

하드론 질량 스펙트럼(수백 종의 입자 질량 패턴)은 FSM 노름(공리 14)의 조합 규칙으로 결정된다. 각 쿼크의 FSM 노름과 CAS 상호작용 비용(포텐셜)의 합이 하드론 질량을 결정하며, 허용되는 조합은 FSM 닫힘 조건(색 싱글렛)에 의해 제약된다.

공리 14(FSM 노름 = 질량), 공리 12(FSM 닫힘 = 색 싱글렛), 공리 4(CAS 비용 = 포텐셜)

공리 14(FSM $000 \to 111$ ==> 노름: 쿼크 종마다 다른 노름), 공리 12(닫힌 FSM만 관측 가능 ==> 색 싱글렛), 공리 4(비용 = 쿼크 간 상호작용 포텐셜), 공리 2(CAS Swap ==> 글루온 교환 비용)

하드론 질량 계층: $m_\pi < m_K < m_\rho < m_p < m_\Delta < \cdots$는 구성 쿼크 FSM 노름의 크기순. 가벼운 쿼크($u, d$) ==> 가벼운 하드론, 무거운 쿼크($c, b$) ==> 무거운 하드론. 궤도 각운동량 기여 = FSM 순환 회전 에너지.

$m_\pi = 140\;\text{MeV}$, $m_\rho = 775\;\text{MeV}$, $m_p = 938\;\text{MeV}$, $m_{J/\psi} = 3097\;\text{MeV}$, $m_\Upsilon = 9460\;\text{MeV}$.

쿼크 모형 질량 공식 $\sim 10{-}20\%$ 정합. 격자 QCD 정밀 계산 $\sim 1\%$.

하드론 스펙트럼, 쿼크 모형, 격자 QCD, PDG 입자표, Regge 궤적(H-507)

새로운 하드론 상태 발견 시 FSM 조합 규칙 검증. 격자 QCD 스펙트럼과 비교.

개별 하드론 질량의 정밀 FSM 도출. 글루볼·혼합 상태의 조합 규칙.

재대입 용도: 재대입 용도: H-502(팔중도) 패턴. H-503(메손 노넷) 분류. H-507(레게 궤적) 각운동량.

5단계 재귀 대입: FSM 노름 합에서 하드론 질량 스펙트럼 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

하드론 질량은 구성 쿼크 각각의 FSM 노름과 쿼크 간 CAS 상호작용 비용의 합이다. FSM 순환 $000\to111$이 한 쿼크의 노름을 정하고(공리 14), 글루온 교환은 CAS Swap 비용으로 들어온다(공리 2). 관측 가능한 조합은 FSM 닫힘이 색 싱글렛을 강제하는 $q\bar{q}$·$qqq$로 한정된다(공리 12).

2단계. 노름 치환

(a) 치환하는 노름은 구성 쿼크 FSM 노름의 합 노름이다. (b) 이 노름을 택하는 이유: 강력은 ring-7 원자성으로 거리 무관 가둠을 주므로, 하드론 질량의 주항은 구성 쿼크 노름 합이고 CAS 비가역 비용(공리 4)이 포텐셜 보정으로 더해지기 때문이다. 표준 모형의 결합 에너지 합을 FSM 노름 합으로 치환한다.

$M_{\text{hadron}} = \sum_i m_i + \langle V_{\text{QCD}}\rangle$
$M_{\text{hadron}} = \sum_i \|\text{FSM}_i\| + V_{\text{CAS}}(\{r_{ij}\})$
$\|\text{FSM}_i\|$: 쿼크 $i$의 FSM 노름 (공리 14) | $V_{\text{CAS}}$: 쿼크 간 CAS 비용 포텐셜 (공리 4) | $\{r_{ij}\}$: 쿼크 쌍 간격 | 조합 $\in\{q\bar{q},\,qqq\}$: FSM 닫힘 (공리 12)

3단계. 상수 대입

$m_\pi$ = 140 $\text{MeV}$ PDG
$m_\rho$ = 775 $\text{MeV}$ PDG
$m_{p}$ = 938 $\text{MeV}$ PDG
$m_{Jpsi}$ = 3097 $\text{MeV}$ PDG
$m_{Upsilon}$= 9460 $\text{MeV}$ PDG

4단계. 도메인 변환

(a) 강력 ring-7 색 도메인으로 변환한다. (b) 보려는 것은 구성 쿼크 노름 순서가 곧 질량 순서가 되는가이다. 가벼운 $u,d$ 노름은 가벼운 하드론, 무거운 $c,b$ 노름은 무거운 하드론을 주므로 노름 합 크기순이 스펙트럼 계층을 결정한다.

$m_\pi < m_K < m_\rho < m_p < m_\Delta < m_{J/\psi} < m_\Upsilon$

5단계. 측정

도출: 질량 = FSM 노름 합 순서
측정: $m_\pi{=}140,\;m_p{=}938,\;m_\Upsilon{=}9460$ MeV (PDG)
오차: 쿼크 모형 $\sim 10{-}20\%$, 격자 QCD $\sim 1\%$

판정: 가설. 노름 합이 계층 순서를 정성적으로 닫지만, 개별 하드론 질량의 정량 계수가 공리에서 직접 도출되지 않아 forward chain 마지막 단계가 미완이다.

통찰: 강력 ring-7 원자성이 노름 합을 거리 무관하게 묶어 수백 종 하드론을 두 조합 $q\bar q$·$qqq$로 가둔다.
