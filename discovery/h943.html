H-943. Berry phase = 단위구 위 닫힌 경로의 둘러싼 입체각 / 2

핵심 발견

H-943: Berry phase = 단위구 위 닫힌 경로의 둘러싼 입체각 / 2

$$\gamma_{\text{Berry}} = \frac{\Omega}{2}, \qquad e^{i\gamma} = e^{i\Omega/2}$$

등급: A (구조 직접)

양자 상태가 매개변수 공간에서 닫힌 경로를 그릴 때 누적되는 기하학적 위상. Berry 1984 발견. 사원수 + 단위구 형식의 직접 적용으로 도출.

공리 1 사원수 명제에서 양자 상태 = 단위구 위 점. 닫힌 경로 = 사원수 회전의 누적. 공리 1 단위원 형식 명제의 (-1)^n 위상이 3D 단위구로 확장된 연속 일반화.

공리 1 (직교) ==> 공리 1 단위원 형식 (위상 = pi × 횡단 수) ==> 공리 1 사원수 명제 (공간 = 단위구) ==> 공리 4 노름 reading (호 누적). 단위구 위 닫힌 경로 둘러싼 면적 = 입체각 Ω. 위상은 호 누적이므로 Ω/2 (구면 면적의 위상 변환).

(-1)^n 단위원 ==> e^(iΩ/2) 단위구. 상태가 단위구 한 바퀴 둘러싸면 Ω = 2pi ==> 위상 = e^(i pi) = -1 (페르미온 위상 자동 등장). 반 바퀴 = Ω = pi ==> e^(i pi/2) = i.

닫힌 경로 둘러싼 입체각 ==> 위상 정확히 Ω/2. 자기 단극자 둘러싸면 Ω = 4pi ==> 위상 2pi (완전 회전) ==> Dirac 양자화 (H-949) 자동 도출.

실험 확인: 광학 Pancharatnam phase (편광 회전), NMR Berry phase, 양자 호 효과. 모두 Ω/2 와 일치.

Berry 1984, Aharonov-Bohm 1959, Pancharatnam 1956, geometric phase, holonomy

양자역학에서 Berry phase 도출은 adiabatic theorem + Berry connection 선적분. 본 가설은 사원수 단위구 위 호 길이로 직접 도출.

Berry phase ≠ Ω/2 측정 시 반박. 현재 모든 실험에서 정확히 Ω/2.

non-Abelian Berry phase (Wilczek-Zee) 의 사원수 표현 — 비가환 회전 누적.

재대입 용도: 재대입 용도: Aharonov-Bohm 위상, H-949 (자기 단극자 양자화), 위상 양자 컴퓨팅, 비가환 게이지 위상.

가설에서 멈춘 이유: 본 카드는 가설(분류 III)로 분류되어 다음 라운드로 미진행한 채 멈춰 있다. 정량 식과 실험값이 둘 다 있지만 forward chain의 마지막 단계가 닫히지 않았다. 식의 모든 계수가 공리 또는 1차 정수에서 직접 도출되지 않고 일부가 외부 입력 또는 가설로 남았다. 잔여 과제 명시: 재대입 용도: 재대입 용도: Aharonov-Bohm 위상, H-949 (자기 단극자 양자화), 위상 양자 컴퓨팅, 비가환 게이지 위상. D 승격 경로는 (1) 위 잔여 과제 해소, (2) 라이브러리의 인접 D/H 카드를 재귀 대입 라운드 입력으로 재투입, (3) 공리 1, 공리 2, 공리 4, 공리 9, 공리 11 명제 중 미적용 명제 추가 도입의 3가지가 표준.

5단계 재귀 대입: 단위구 호 누적 노름에서 Berry phase $\gamma=\Omega/2$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

기하 위상은 양자 상태가 단위구 위에서 그리는 닫힌 경로의 호 누적 비용으로 읽는다. 공리 1 사원수 명제에서 양자 상태는 단위구($S^2$) 위 점이고, 닫힌 경로는 사원수 회전의 누적이다.

2단계. 노름 치환

(a) 치환하는 노름은 단위구 호 누적 노름이다 — 공리 4 노름 reading에서 위상은 호 길이로 읽힌다. (b) 이 노름을 택하는 이유: 단위원 형식 명제(공리 1)의 위상 $e^{i\theta}$가 단위구로 확장되면, 닫힌 경로가 둘러싸는 면적은 입체각 $\Omega$가 되고 위상은 그 절반의 호로 누적된다. 양쪽 곱 반각 구조와 동일하게 면적이 위상으로 갈 때 인자 $1/2$가 붙는다.

$e^{i\gamma} = e^{i\theta}\big|_{S^1} \;\text{(단위원)}$
$\gamma_{\text{Berry}} = \dfrac{\Omega}{2}, \qquad e^{i\gamma} = e^{i\Omega/2}$
$\gamma_{\text{Berry}}$: 기하 위상 | $\Omega$: 닫힌 경로가 둘러싼 입체각 | $1/2$: 면적 $\to$ 호 위상 반각 인자 (공리 4 노름 reading) | $S^2$: 단위구 (공리 1 사원수 명제)

3단계. 상수 대입

한 바퀴 둘러쌈  Omega = 2 pi -> gamma = pi   -> e^(i pi) = -1
반 바퀴        Omega = pi   -> gamma = pi/2 -> e^(i pi/2) = i
단극자 둘러쌈  Omega = 4 pi -> gamma = 2 pi -> 완전 회전 (H-949)

4단계. 도메인 변환

(a) 변환하는 도메인은 단위구 입체각 도메인이다. (b) 보려는 것은 매개변수 공간 닫힌 경로가 누적하는 기하 위상이다. 경로가 둘러싼 입체각 $\Omega$에 반각 인자 $1/2$를 곱하면 위상이 정확히 산출된다.

$\Omega = 2\pi \;\Rightarrow\; \gamma = \pi \;\Rightarrow\; e^{i\gamma} = -1$

5단계. 발견

도출: $\gamma_{\text{Berry}} = \Omega/2$
측정: Pancharatnam 광학 위상, NMR Berry 위상 모두 $\Omega/2$
정합: 정성 100% (모든 실험에서 정확히 $\Omega/2$)

판정: 가설. 위상 $\Omega/2$가 호 누적 노름에서 직접 따라오고 $\Omega=4\pi$에서 Dirac 양자화(H-949)가 자동으로 닫히지만, 도메인이 자연 분류 밖이라 forward chain 마지막 단계가 미확정이다.
