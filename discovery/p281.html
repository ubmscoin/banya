P-281. 양자 상태 식별 최소 오류 = 1/2(1-√$(1-|{\langle}\psi|\phi{\rangle}|^{2})$)

핵심 발견

P-281: 양자 상태 식별 최소 오류 = 1/2(1-√$(1-|{\langle}\psi|\phi{\rangle}|^{2})$)

$$P_{\text{err}}^{\min}=\frac{1}{2}\Big(1-\sqrt{1-|\langle\psi|\phi\rangle|^2}\Big)\;(\text{Compare 분기 모호도})$$

예측: 등확률 두 비직교 상태의 최소 식별 오류는 헬스트롬 한계 ½(1-√$(1-|{\langle}\psi|\phi{\rangle}|^{2})$)이며, 직교(겹침 0) 시 오류 0, 동일(겹침 1) 시 오류 ½로 닫힌다 — Compare 분기 모호도가 겹침에서 결정된다. (finding-precision: 정확)

반야식 $\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$에서 두 비직교 상태 구별의 최소 오류 확률 (헬스트롬)는 Compare 분기 모호도 = 두 상태 겹침에서 도출된다 (공리 2, 공리 7, 공리 1, 공리 13).

H-446(측정 문제 해소=Compare true/false가 전부)는 정성이다. Compare 분기 모호도가 두 상태 겹침으로 정량화되어 헬스트롬 최소 오류로 닫히므로 예측이다.

(a)Compare 분기 모호도 노름 (b)겹침이 클수록 Compare 오판 확률 증가.

검증: 광자 편광 두 상태 식별 실험에서 겹침을 바꾸며 최소 오류가 헬스트롬 곡선을 따르는지 확인(표준 정합 + Compare 도출).

$P_{\text{err}}=\frac{1}{2}(1-\|p_1\rho_1-p_2\rho_2\|_1)$
$P_{\text{err}}^{\min}=\frac{1}{2}\Big(1-\sqrt{1-|\langle\psi|\phi\rangle|^2}\Big)$
$P_{\text{err}}$: 최소 식별 오류 | $\langle\psi|\phi\rangle$: 두 상태 겹침 = Compare 모호도 (공리 2) | 겹침 0 = 직교 = 오류 0 | 겹침 1 = 동일 = 오류 1/2

3단계. 상수 대입

등확률 $p_1=p_2=1/2$
$|\langle\psi|\phi\rangle|\in[0,1]$
Compare 분기 = 2 (공리 2)

4단계. 도메인 변환

(a)양자 상태 식별 도메인 (b)두 상태를 얼마나 잘 구별할 수 있는가 본다.

$|\langle\psi|\phi\rangle|=0\Rightarrow P_{\text{err}}=0;\quad |\langle\psi|\phi\rangle|=1\Rightarrow P_{\text{err}}=\tfrac{1}{2}$
