5단계 재귀 대입: CAS 원자성 Read 경로 자유도에서 게이지 불변성 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

게이지 자유도는 CAS가 원자 사이클로 닫히는(공리 2) 동안 Read 경로를 잡는 위상 자유도다. Swap은 Compare의 bool 결과에만 의존하고(공리 7 Compare이면 Swap), Read 오프셋에는 의존하지 않으므로(공리 14 FSM 닫힘) 그 오프셋이 곧 게이지 자유도다.

2단계. 노름 치환

치환하는 노름은 Read 경로 위상 노름이다. 물리량(Swap 결과)이 Read 오프셋의 변화에 불변이기 때문에 이 노름을 택한다. Read 오프셋을 임의 위상으로 옮겨도 Compare bool이 같으면 Swap이 같아, 퍼텐셜에 $\partial_\mu\chi$를 더하는 게이지 변환이 관측량을 바꾸지 않는다.

$A_\mu \mapsto A_\mu + \partial_\mu\chi$
$\text{Swap} = f(\text{Compare bool}),\qquad \dfrac{\partial\,\text{Swap}}{\partial(\text{Read offset})} = 0$
$A_\mu$: 게이지 퍼텐셜 | $\chi$: Read 오프셋 위상 | Compare bool: 공리 7 비교 결과 | Swap: 공리 2 CAS 쓰기 단계

3단계. 상수 대입

U(1)  = Read 경로 1개          전하 보존
SU(2) = Read 채널 2개 비가환    약한 동위스핀 보존
SU(3) = Read 채널 3개 비가환    공리 2 CAS 3축
관측량 = Swap 결과 (Read 오프셋 불변)

4단계. 도메인 변환

게이지 대칭 도메인으로 변환한다. 이 변환으로 보려는 것은 Read 오프셋 위상에 대한 관측량의 불변성이다. Swap이 Compare bool만의 함수임을 대입하면 게이지 변환 아래 관측량의 변화가 0으로 산출된다.

$\delta(\text{observable}) = 0\quad\text{under}\quad A_\mu \mapsto A_\mu + \partial_\mu\chi$

5단계. 발견

도출값: 관측량 게이지 불변 ($U(1)$ Read 경로 1개)
측정값: $U(1)$ 전하 보존, $SU(2)$ 약한 동위스핀 보존 (표준모형 확인)
정합: Yang-Mills 게이지 구조와 일치

판정: 가설. Read 오프셋 불변이 게이지 불변성을 강제하는 구조는 닫혔으나, $SU(2)$·$SU(3)$의 다중 Read 채널 비가환성 형식화가 미완이라 가설에 머문다.

게이지 자유도는 Compare bool이 같으면 Read 경로를 자유롭게 고를 수 있는 CAS 원자성의 잉여다.
