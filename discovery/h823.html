H-823. 신경 발화 = delta 발화의 뉴런 규모 실현

핵심 발견

H-823: 신경 발화 = δ 발화의 뉴런 규모 실현

$$\text{Action Potential} \;\leftrightarrow\; \delta_{\text{neuron}} \text{ 발화: 역치 초과 → 전역 전파 → 복귀}$$

등급: C

뉴런의 활동 전위(action potential)는 역치를 넘으면 전부-아니면-전무(all-or-none) 방식으로 발화한다. 반야에서 δ 발화(공리 15)와 동일한 구조이다: 역치 초과 ==> bit7 점등 ==> 전역 전파 ==> 감쇠 복귀.

공리 15(δ 발화 = bit7), 공리 8(링버퍼 = 시간적 전파)

공리 15(δ = 전역 플래그, 발화 = bit7 점등). 뉴런의 활동 전위 = δ 발화의 분자/세포 규모 실현. 역치($\sim -55\;\text{mV}$) = δ 발화 조건. 불응기 = 링버퍼 1틱 소요. 시냅스 전달 = δ 발화의 엔티티 간 전파.

뉴런 발화의 all-or-none = δ의 이진 특성(0 또는 1). 발화 빈도 부호화 = 링버퍼에서의 δ 발화 밀도. 시냅스 가소성 = CAS Compare의 반복적 비용 변화(헤브 학습). 의식(H-835) = 대규모 δ 발화 동기화.

발화 빈도: 1~200 Hz. 활동 전위 지속: $\sim 1\;\text{ms}$.

신경 생리학과 정합.

활동 전위, 뉴런 발화, 시냅스, 불응기, 헤브 학습

δ 발화 모형으로 뉴런 발화 시뮬레이션.

δ 발화 역치와 뉴런 역치의 정량적 대응.

재대입 용도: 재대입 용도: H-824(뇌파). H-835(의식과 복잡성)

5단계 재귀 대입: delta 발화비트 비용에서 신경 활동 전위 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

활동 전위는 δ 발화(공리 15: δ = 전역 플래그, 발화 = bit7 점등)가 뉴런 규모로 실현된 것이다. 막전위가 역치를 넘으면 bit7이 켜지고, 전역 전파 후 링버퍼 1틱(공리 8) 동안 불응기로 복귀한다. 발화는 전부-아니면-전무이므로 δ의 이진 특성과 동형이다.

2단계. 노름 치환

(a) 치환하는 노름은 δ 발화비트(bit7) 노름이다. 역치 초과 1회가 bit7 점등 1회로 환원되고, 발화 후 다음 발화까지 링버퍼 1틱의 불응기가 강제된다. (b) 활동 전위를 이 노름으로 택하는 이유는 뉴런의 all-or-none이 0/1 한 비트의 점등이고, 불응기가 링버퍼 1틱(공리 8)이라는 시간 양자로 닫히기 때문이다. 최대 발화율은 불응기의 역수로 정해진다.

$\delta_{\text{fire}} = [\,V_m > V_{\text{th}}\,] \implies \text{bit7} = 1$
$f_{\max} = 1/\tau_{\text{ref}}$
$V_m$: 막전위 | $V_{\text{th}}$: 역치 | bit7: δ 발화비트(공리 15) | $\tau_{\text{ref}}$: 불응기 = 링버퍼 1틱(공리 8) | $f_{\max}$: 최대 발화율

3단계. 상수 대입

V_th     = -55 mV         발화 역치
AP width = 1 ms           활동 전위 지속
tau_ref  ~ 5 ms           불응기 1틱
f range  = 1 .. 200 Hz    발화 빈도

4단계. 도메인 변환

(a) 변환 도메인은 뉴런 발화율 도메인이다. (b) 보려는 것은 불응기 한 틱이 정하는 최대 발화율, 곧 $f_{\max}$다. 불응기 $\tau_{\text{ref}}$의 역수로 산출한다.

$f_{\max} = 1/\tau_{\text{ref}} = 1/(5\;\text{ms}) = 200\;\text{Hz}$

5단계. 발견

도출값: $f_{\max} = 200\;\text{Hz}$ (불응기 1틱 = 5 ms)
측정값: 발화 빈도 $1$~$200\;\text{Hz}$, 활동 전위 $1\;\text{ms}$
상태: 발화율 상한 구조 일치, 역치 절댓값 닫힘 미완

판정: 가설. all-or-none 발화가 bit7 점등에, 최대 발화율이 링버퍼 1틱에 대응하나, 역치 $-55$ mV가 공리 정수에서 도출되지 않아 가설에 머문다.
