H-709. 광탄성 효과 = 응력에 의한 도메인 비트 변형

핵심 발견

H-709: 광탄성 효과 = 응력에 의한 도메인 비트 변형

$$\Delta n_{ij} = C_{ijkl}\sigma_{kl} \;\leftrightarrow\; \text{응력 텐서에 의한 CAS 비용 전파 비등방성 변화}$$

등급: C

광탄성 효과는 기계적 응력이 매질의 CAS 비용 전파 속도(굴절률)를 비등방적으로 변화시키는 현상이다. 등방성 매질이 응력 하에서 복굴절을 보인다.

H-696(편광), 공리 4(CAS 비용 전파)

공리 4(비용 전파 속도 = 매질 CAS 밀도 의존), H-696(편광 = 도메인 비트 방향), 공리 7(ECS 격자 변형 ==> 비등방성)

응력 복굴절 = 주응력 방향에 따른 도메인 비트 분리. 광탄성 상수 $C$ = 응력-굴절률 결합 계수. 광탄성 응력 분석: 프린지 패턴 ==> 응력 분포 재구성.

유리 광탄성 상수: $C \approx 2.7\;\text{TPa}^{-1}$. 에폭시: $C \approx 50\;\text{TPa}^{-1}$.

광탄성 응력 분석과 정합.

광탄성 효과, 응력 복굴절, 광탄성 응력 분석

광탄성 응력 분석법으로 검증. 구조 공학 표준 기법.

CAS 비용 격자 변형에서 광탄성 텐서의 미시적 도출.

재대입 용도: 재대입 용도: H-696(편광) 복굴절 응용. H-711(커 효과) 외부장 대비

5단계 재귀 대입: 응력에 의한 CAS 비용 전파 비등방성에서 광탄성 복굴절 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

광탄성 효과는 기계적 응력이 매질 안 CAS 비용 전파 속도(굴절률)를 방향마다 다르게 바꾸는 비용이다(공리 4 비용 전파 속도 = 매질 CAS 밀도 의존). 편광은 도메인 비트 방향이고(H-696), ECS 격자가 응력으로 변형되면 비용 전파가 비등방이 된다(공리 7).

2단계. 노름 치환

(a) 치환하는 노름은 응력-굴절률 결합 노름, 곧 광탄성 텐서 $C_{ijkl}$다. (b) 등방성 매질은 모든 도메인 비트 방향이 같은 비용 전파 속도를 갖지만, 주응력이 가해지면 주응력 방향에 따라 도메인 비트가 분리되어 두 굴절률로 갈라지므로 굴절률 변화 노름은 응력 텐서에 선형으로 치환된다.

$\Delta n_{ij} = C_{ijkl}\,\sigma_{kl}$
$\Delta n = C\,(\sigma_1 - \sigma_2)$
$\Delta n_{ij}$: 굴절률 변화 텐서 | $C_{ijkl}$: 광탄성 텐서 | $\sigma_{kl}$: 응력 텐서 | $\sigma_1,\sigma_2$: 주응력 | $C$: 응력-광학 상수

3단계. 상수 대입

C(유리)   = 2.7e-12 Pa^-1        2.7 TPa^-1, 광탄성 응력 분석
C(에폭시) = 50e-12 Pa^-1         50 TPa^-1
sigma     = 10 MPa = 1e7 Pa      예시 응력

4단계. 도메인 변환

(a) 광탄성 응력 분석 도메인(프린지 패턴)으로 변환한다. (b) 보려는 것은 주어진 응력이 만드는 복굴절 $\Delta n$, 곧 프린지 패턴으로 응력 분포를 재구성하는 양이다. 유리에 $10\,\text{MPa}$ 응력을 대입한다.

$\Delta n = 2.7\times10^{-12}\times10^{7} = 2.7\times10^{-5}$

5단계. 발견

도출: $\Delta n = 2.7\times10^{-5}$ (유리, $10\,\text{MPa}$)
측정: $C_{\text{유리}}\approx2.7\,\text{TPa}^{-1}$, 광탄성 응력 분석

판정: 가설. 응력에 선형인 복굴절 형태는 도메인 비트 분리 노름에서 닫혔으나, 광탄성 텐서 $C_{ijkl}$를 CAS 비용 격자 변형에서 미시적으로 도출하는 마지막 단계가 미완이라 가설에 멈춘다.

통찰: 응력 하 유리의 무지개 프린지는 도메인 비트가 주응력 방향으로 분리되어 비용 전파가 두 속도로 갈라지는 비등방성의 직접 가시화다.
