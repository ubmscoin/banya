P-403. 콘도 최소 저항 = 읽기 경합 로그 도출

핵심 발견

P-403: 콘도 최소 저항 = 읽기 경합 로그 도출

$$\rho(T)=\rho_0+aT^5-b\ln\frac{T}{T_K},\quad \ln\ \text{항}\Leftarrow\text{비용 0 가역 스핀 뒤집기 (반복 읽기 경합)}$$

예측: 자성 불순물 금속은 저온에서 저항 극소를 보이며 -b $ln(T/T_K)$ 로그 상승이 동반된다 — 이는 lock 비트(스핀) 뒤집기가 비용 0의 가역 반복 읽기 경합이기 때문이다. 검증 희박 자성합금 저온 저항(즉시~). (finding-precision)

반야식 $\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$에서 콘도 저항 극소의 온도 의존 형태는 자성 불순물 읽기 경합의 로그 비용에서 도출된다 (공리 4, 공리 6, 공리 11).

H-627/H-631이 자성과 산란을 따로 대응하고 콘도 로그 항을 비웠다. 가역 lock 뒤집기 = 반복 읽기 경합 로그로 닫혀 예측이다.

(a)cost reading (b)로그 항은 비용 0 가역 lock 뒤집기의 반복 읽기 경합 발산이다.

검증: 희박 자성합금(Cu:Fe, Au:Mn 등) 저온 저항에서 극소와 로그 상승 확인 (즉시~)

반박: 자성 불순물 금속에서 저온 저항 극소/로그 상승이 부재하면 반증

$\rho(T)=\rho_0+aT^5-b\ln(T/T_K)$
$-b\ln(T/T_K)\Leftarrow\text{lock 뒤집기 = 가역(비용 0) 반복 읽기 경합 (공리 4 명제, 11 명제)}$
$\rho_0$: 잔류 저항 | $T_K$: 콘도 온도 | $aT^5$: 포논 (블로흐) | $-b\ln$: 자성 산란 = 가역 lock 뒤집기 반복 읽기 경합 (공리 11 명제) | 극소 = 경쟁

3단계. 상수 대입

lock 뒤집기 = 가역(비용 0) (공리 4 명제)
읽기 경합 = 상호작용 (공리 11 명제)
반복 = 로그 발산

4단계. 도메인 변환

(a)time 도메인 (b)콘도 저항 극소의 로그 상승이 가역 lock 반복 읽기 경합인지 본다.

$\frac{d\rho}{dT}=5aT^4-\frac{b}{T}=0\ \Rightarrow\ T_\text{min}=(b/5a)^{1/5}$
