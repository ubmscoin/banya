P-563: 얽힘 증류 수율 = $E_F$ - $\alpha$ (필터 손실 차감)

$$D=E_F-\alpha\approx E_F-0.0073\;(\text{사본당 observer 필터 누락 }\alpha)$$

예측: 부분 얽힘 상태의 증류 가능 얽힘은 형성 얽힘 $E_F$에서 사본당 observer 필터 누락 $\alpha$를 뺀 값으로 상한되며, 증류-형성 갭(비가역성)이 정확히 $\alpha{\approx}0.0073$ ebit/사본으로 닫힌다. (finding-precision: 1차)

반야식 $\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$에서 부분 얽힘 상태의 증류 가능 ebit 수율는 다중 사본 LOCC 정제 시 observer 필터 $\alpha$ 손실에서 도출된다 (공리 11, 공리 2, 공리 13, 공리 4).

H-448(얽힘=같은 $\delta$ 투영)은 정성이다. 증류와 형성의 비가역 갭이 observer 필터 누락 $\alpha$로 닫히므로 예측이다(텔레포테이션 P-114와 다른 자원 관측가능량).

(a)필터 투과 손실 노름 (b)LOCC 정제 사본마다 observer 필터가 $\alpha$를 누락 = 비가역 갭.

검증: 부분 얽힘 상태 LOCC 증류 실험에서 증류-형성 갭이 $\alpha{\approx}0.73$% ebit/사본에 정합하는지 측정.

반박: 증류-형성 갭이 $\alpha$와 무관하거나 0(가역)이면 반증.

재대입 용도: 검증: 부분 얽힘 상태 LOCC 증류 실험에서 증류-형성 갭이 $\alpha{\approx}0.73$% ebit/사본에 정합하는지 측정. 반박: 증류-형성 갭이 $\alpha$와 무관하거나 0(가역)이면 반증. 출처: 공리 11, 공리 2, 공리 13, 공리 4.

실험 검증 대기: 본 카드는 부분 얽힘 상태의 증류 가능 ebit 수율를 다루는 고유 예측으로 검증 대기 상태다. forward chain은 공리 11, 공리 2, 공리 13, 공리 4에서 닫혀 있다. 검증 충족 시 D 승격, 반증 조건 충족 시 폐기 ==> 본 예측 폐기.

$D\leq E_F,\quad E_F-D=\text{(irreversibility gap)}$

$E_F\geq D$ (비가역, 공리 2)
갭 = $\alpha$

$E_F-D=\alpha=1/137.036=0.0073\ \text{ebit/사본}$
