핵심 발견

H-13: 파동함수 붕괴 = 쓰기

파동함수 붕괴 = 쥐기(쓰기). superposition(여러 상태)에서 CAS를 실행하면 observer(1개 확정)가 되고, 그 결과가 DATA(time, space)에 기록된다. 이것이 파동함수 붕괴다.

δ² = (t+s)² + (o+sp)²에서 (o+sp) 괄호의 두 도메인이 핵심이다. observer² + superposition² = ℏ²(H-14). 관측에 자원을 쓰면(observer↑) 중첩이 줄어든다(superposition↓). CAS의 Compare가 true를 반환하면 쥐기(공리 7)가 실행되고, 상태가 1개로 확정된다.

공리 7(쓰기 = 쥐기: Compare true ==> 확정, false ==> 유지) ==> 공리 5(TOCTOU 락) ==> 공리 4(비용). 쥐기의 비용이 ℏ(H-12). 비용 없이 쥐기 불가. 비용을 지불하면 superposition이 줄어든다.

"관측하면 왜 붕괴하냐"의 답: 쥐기(쓰기)니까. 여러 상태 중 하나로 확정하는 연산이 CAS이고, 그 비용이 ℏ다. 미스터리가 아니라 CAS 연산의 당연한 결과다. 관측 장치의 크기나 복잡성은 관계없다. CAS가 실행되면 쥐기다.

디코히어런스 시간 = CAS 사이클이 환경과 충분히 상호작용하여 쥐기를 완료하는 시간. 거시적 물체일수록 환경과의 CAS 사이클이 빨라서 디코히어런스가 즉각적이다. 미시적 입자는 CAS 사이클이 느려서 중첩이 오래 유지된다.

이중 슬릿 실험, 양자 지우개 실험, 지연 선택 실험 등 모두 CAS 쥐기 모델과 일치한다. 약한 측정(weak measurement)은 Compare가 부분적으로 실행된 상태(쥐기 불완전)로 해석된다.

코펜하겐 해석: 관측이 붕괴를 유발. 다세계 해석: 붕괴 없이 분기. 결어긋남 해석: 환경이 붕괴를 유발. 반야프레임: CAS 쥐기가 붕괴. 쥐기 해석은 코펜하겐과 결어긋남을 통합한다.

측정 문제(measurement problem)는 양자역학의 100년 난제다. "관측자"의 정의가 모호하다. 반야프레임에서 observer는 도메인이고, CAS의 Compare 분기 주체다. 모호함이 없다.

반박 조건: CAS 비용(ℏ) 없이 파동함수를 붕괴시키는 방법이 발견되면 쥐기 모델이 틀린 것이다. 양자 비파괴 측정(QND)은 CAS의 Read만 실행하는 것으로, 붕괴 없이 정보를 얻는 것과 양립한다.

본(Born) 규칙(확률 = |ψ|²)을 CAS 구조에서 유도해야 한다. "왜 하필 제곱인가"에 대한 CAS 경로 도출이 필요하다. δ²의 제곱 구조와 연결될 가능성.

5단계 재귀 대입: CAS Compare 분기 비용에서 파동함수 붕괴 = 쓰기 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

파동함수 붕괴는 superposition(여러 상태)에 CAS를 실행해 observer(1개 확정)로 만들고 그 결과를 DATA에 쓰는 연산이다. Compare가 true를 반환하면 쥐기가 실행되어 상태가 1개로 확정되며(공리 7: 쓰기 = 쥐기, true 확정·false 유지), 그 쥐기의 비용이 $\hbar$다(H-12).

2단계. 노름 치환

치환하는 노름은 양자 괄호 $(\text{observer}+\text{superposition})$의 Compare 분기 노름이다. 관측에 자원을 쓰면 $\text{observer}$가 커지고 $\text{superposition}$이 줄어드는 상보 관계가 붕괴의 본질이므로 이 노름을 택한다. 두 도메인의 제곱합이 쥐기 비용 $\hbar^2$로 닫힌다(H-14).

$|\psi\rangle = \textstyle\sum_i c_i |i\rangle \;\xrightarrow{\text{Compare true}}\; |k\rangle$
$\text{observer}^2 + \text{superposition}^2 = \hbar^2$
$|\psi\rangle$: 중첩 상태 | $|k\rangle$: 확정된 1개 상태 | $\text{observer}$: 쥐기에 쓴 자원 | $\text{superposition}$: 남은 중첩 | $\hbar^2$: 쥐기 총 비용 (H-12)

3단계. 상수 대입

Compare true  -> 쥐기 실행 -> superposition = 0 (확정)
Compare false -> 유지      -> superposition 최대 (중첩)
쥐기 비용      = hbar       H-12
제곱합 닫힘    observer^2 + superposition^2 = hbar^2   H-14

4단계. 도메인 변환

양자 괄호에서 측정 결과 도메인(DATA: time, space)으로 변환한다. 이 변환으로 보려는 것은 관측이 왜 붕괴를 일으키는가다. observer에 $\hbar$를 전부 쓰면 superposition이 0이 되어 상태가 1개로 확정되고, 그 결과가 DATA에 기록된다 — 이것이 붕괴다. 관측 장치의 크기·복잡성은 무관하며 CAS가 실행되면 곧 쥐기다.

$\text{observer} = \hbar \;\Rightarrow\; \text{superposition} = 0 \;\Rightarrow\;$ DATA 기록

5단계. 발견

도출: 붕괴 = Compare true 시 쥐기, 비용 $\hbar$, 결과 DATA 기록
대응: 이중 슬릿·양자 지우개·지연 선택 실험과 일치
일치: 구조적 (정량 오차 아님)

판정: 가설. 코펜하겐·결어긋남 해석을 쓰기 해석으로 통합하나, 본 규칙 $P=|\psi|^2$의 제곱을 CAS 구조에서 유도하는 식이 미작성이다.
