H-862. 광통신 = 광자(FSM 노름=0)의 비용 전달

핵심 발견

H-862: 광통신 = 광자(FSM 노름=0)의 비용 전달

$$C = B\log_2\left(1 + \frac{P}{N_0 B}\right) \;\;\text{(광자 = FSM 노름 0 → 광섬유 전송 → 샤논 용량)}$$

등급: B

광통신은 광자(FSM 노름=0인 보손)를 광섬유를 통해 전달하여 DATA를 전송하는 기술이다. 광섬유 = ECS 도파관. 광자의 무질량 = 최고속 전달. 파장분할다중화(WDM) = 다수 CAS 비용파 병렬 전송.

공리 3(FSM 노름=0 = 광자), 공리 7(비용 전달 = 광 전송), 공리 2(ECS 도파관 = 광섬유)

공리 3: 광자 = FSM 노름 0. 질량 없는 비용 전달자. 광섬유 내부에서 전반사로 가둠. 공리 7: 비용 전달 = 광 신호. 감쇠: $\sim 0.2\;\text{dB/km}$ (1550 nm). WDM: 다수 파장 병렬 전송. 공리 2: ECS 도파관 = 코어+클래딩 구조. 전반사 조건 = 스넬 법칙.

단일모드 섬유: 코어 $\sim 9\;\mu\text{m}$. 다중모드: 코어 $\sim 50\;\mu\text{m}$. EDFA: 에르븀 도핑 증폭. DWDM: 80+ 채널 병렬. 해저 케이블: 대륙간 연결.

최대 전송 속도: $\sim 100\;\text{Tbps}$(실험실). 상업: $\sim 10\;\text{Tbps}$. 감쇠: $0.2\;\text{dB/km}$. 중계 간격: $\sim 80$~$100\;\text{km}$.

광섬유 감쇠 이론(레일리 산란)과 실측 $< 5\%$ 정합.

광통신, 광섬유, WDM, EDFA, 전반사, 레일리 산란

광섬유 통신 노벨상(2009). 글로벌 인터넷 인프라.

FSM 노름=0 모델에서 비선형 광학 효과의 체계적 도출.

5단계 재귀 대입: 광자 FSM 노름=0에서 광섬유 감쇠 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

광통신은 FSM 노름이 0인 비용 전달자(광자, 공리 3)가 ECS 도파관을 따라 비용을 옮기는 과정이다. 노름 0이므로 전달자가 정지 비용 없이 최고속으로 이동하고, 채널이 잃는 것은 산란으로 새는 비용뿐이다. 이 손실을 $\delta^2$의 space 항에서 거리당 비용으로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 광자 비용의 전파 노름, 곧 ECS 도파관을 따라가는 거리당 감쇠다. (b) 채널 용량은 샤논 한계로 닫히지만 실제 거리 한계를 정하는 것은 레일리 산란 손실이고, 이 산란이 파장 노름 $\lambda^{-4}$로 닫히기 때문에(공리 7 비용 전달) 파장 노름을 택한다. 따라서 거리당 감쇠를 파장 의존 산란 계수로 치환한다.

$C = B\log_2\!\left(1 + \dfrac{P}{N_0 B}\right)$
$\alpha_{\text{dB}} = \dfrac{A}{\lambda^4}$
$C$: 샤논 채널 용량 | $\alpha_{\text{dB}}$: 거리당 감쇠 (dB/km) | $\lambda$: 광 파장 | $A$: 레일리 산란 계수 | $N_0$: 잡음 비용 밀도 (FSM 노름 0 바닥)

3단계. 상수 대입

$\lambda$ = 1550 $\text{nm}$ 통신 표준창
A = 1.16 $dB/\text{km}{\cdot}um^{4}$ 실리카 레일리 계수
$\alpha_{dB}(meas)$= 0.20 $dB/\text{km}$ ITU-T 1550 $\text{nm}$ 실측
C(max) = $\sim$ 100 Tbps 실험실 WDM

4단계. 도메인 변환

(a) 무차원 산란 노름에서 전자기 전송 도메인(거리당 감쇠)으로 변환한다. (b) 보려는 것은 광자 비용이 1 km당 잃는 양, 곧 중계 간격을 정하는 감쇠 $\alpha_{\text{dB}}$다. $A/\lambda^4$를 1550 nm에서 계산해 그 값을 산출한다.

$\alpha_{\text{dB}} = \dfrac{1.16\;\text{dB/km}\cdot\mu\text{m}^4}{(1.55\;\mu\text{m})^4} = \dfrac{1.16}{5.77}\;\text{dB/km} = 0.201\;\text{dB/km}$

5단계. 발견

도출값: $\alpha_{\text{dB}} = 0.201\;\text{dB/km}$
측정값: $0.20\;\text{dB/km}$ (ITU-T, 1550 nm)
오차: $< 5\%$

판정: 가설. 레일리 $\lambda^{-4}$ 산란이 1550 nm 감쇠 $0.2\;\text{dB/km}$를 오차 $<5\%$로 재현하지만, 산란 계수 $A$가 실리카 굴절률 요동에서 외부 입력으로 들어와 공리 정수로 닫히지 않아 가설에 머문다. FSM 노름 0이 정지 비용 없는 최고속 전달을 보장하므로 광자가 비용 전달자의 자연 선택임이 공리 3에서 따라온다.
