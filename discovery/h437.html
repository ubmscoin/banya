H-437. 광전효과 문턱 = CAS Compare 활성화 최소 에너지

핵심 발견

H-437: 광전효과 문턱 = CAS Compare 활성화 최소 에너지

$$E_k = h\nu - W$$

등급: A

일함수 $W$ = Compare 활성화 최소 비용. $h\nu < W$ ==> Compare false ==> Swap 없음 ==> 전자 방출 없음. CAS 원자성 ==> 광자 수 무관.

공리 7(Compare==>Swap), 공리 2(원자적)

공리 7(Compare==>Swap), 공리 2(원자적, 부분 활성화 불가), 공리 4(최소 경계 수)

빛 세기(광자 수) 아닌 진동수가 결정적. $E_k = h\nu - W$ 선형.

세슘: $W = 2.1$ eV, $\nu_0 = 5.1 \times 10^{14}$ Hz.

광전효과 실험(Lenard, Millikan)과 완전 정합.

광전효과(1905, Einstein), 일함수

문턱 진동수 이하에서 전자 방출 없음 확인.

다광자 과정의 CAS 다단계 모델

재대입 용도: 재대입 용도: H-431(전하 양자화) 에너지 양자. D-01(α) 광자 에너지 기반.

가설에서 멈춘 이유: 본 카드는 가설(분류 III)로 분류되어 다음 라운드로 미진행한 채 멈춰 있다. 정량 식과 실험값이 둘 다 있지만 forward chain의 마지막 단계가 닫히지 않았다. 식의 모든 계수가 공리 또는 1차 정수에서 직접 도출되지 않고 일부가 외부 입력 또는 가설로 남았다. 잔여 과제 명시: 재대입 용도: 재대입 용도: H-431(전하 양자화) 에너지 양자. 왜 이 판정인가

이유: 재귀 입력 2개 확인, 다음 라운드 진행 시 D 승격 가능 / 잔여 과제 명시

위치: 카테고리: h measurement. 도메인: delta ==> Compare 분기 (true ==> Swap ==> DATA / false ==> 중첩 유지). 재귀 대입 경로: D-01, H-431

5단계 재귀 대입: CAS Compare 활성화 비용에서 광전효과 문턱 $E_k = h\nu - W$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

광전 방출은 광자 한 개가 CAS Compare를 활성화해 Swap을 일으키는 비용이다. Compare가 참이어야 Swap이 쓰이고(공리 7: Compare true이면 Swap, false이면 중첩 유지), CAS는 원자적이라 부분 활성화가 불가능하므로(공리 2) 광자 에너지가 활성화 최소 비용 $W$를 넘어야 한다는 문턱을 $\delta^2$ 비용 경계로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 Compare 활성화 비용 노름으로, 일함수 $W$가 그 최소 경계 수다(공리 4: 최소 경계 수). (b) 이 노름을 택하는 이유는 CAS 원자성 때문에 빛 세기(광자 수)가 아니라 광자 하나의 진동수가 활성화 여부를 단독으로 정하기 때문이다 — $h\nu < W$이면 Compare false, Swap 없음, 방출 없음. 따라서 방출 전자의 운동에너지를 광자 에너지에서 활성화 비용을 뺀 잔여로 치환한다.

$E_k = E_{\text{photon}} - E_{\text{activation}}$
$E_k = h\nu - W$
$E_k$: 방출 전자 운동에너지 | $h\nu$: 광자 에너지 (CAS 비용 패킷) | $W$: 일함수 = Compare 활성화 최소 비용(공리 4) | 원자성: 부분 활성화 불가(공리 2)

3단계. 상수 대입

h = $4.1357\times10^{-15}$ $\text{eV}\times$ s
W(Cs) = 2.1 $\text{eV}$ 세슘 일함수
$\nu_{0}$ = W/h = $5.1\times10^{14}$ $\text{Hz}$ 문턱 진동수
조건 = $h\times$ $\nu$ < W => 방출 없음

4단계. 도메인 변환

(a) Compare 분기 도메인(true이면 Swap이면 DATA, false이면 중첩 유지)으로 변환한다. (b) 보려는 것은 문턱 진동수 $\nu_0 = W/h$로, 이 아래에서는 광자 수와 무관하게 방출이 0이다. 세슘 $W = 2.1$ eV를 $h$로 나눠 그 값을 산출한다.

$\nu_0 = \dfrac{W}{h} = \dfrac{2.1}{4.1357\times10^{-15}} = 5.1\times10^{14}\ \text{Hz}$

5단계. 발견

도출: $E_k = h\nu - W$, 문턱 $\nu_0 = 5.1\times10^{14}$ Hz (Cs)
측정: Lenard·Millikan 광전 실험, 1905 Einstein
정합: 선형 $E_k$-$\nu$ 관계 및 세기 무관성 일치

판정: 가설. Compare 원자성에서 문턱 구조는 닫히나 일함수 $W$가 물질별 외부 입력이라 forward chain 마지막 단계가 열려 있다.
