H-850. LED = 역방향 광전효과 = Swap==>광자 방출

핵심 발견

H-850: LED = 역방향 광전효과 = Swap==>광자 방출

$$E_{\text{photon}} = h\nu = E_g \;\;\text{(전자-정공 재결합 = Swap → 광자 방출)}$$

등급: C

LED(발광다이오드)는 광전효과의 역과정이다. 전자-정공 재결합(Swap) 시 FSM 노름 차이에 해당하는 에너지가 광자로 방출된다. 밴드갭 $E_g$가 방출 광자의 파장을 결정한다.

공리 5(CAS Swap = 재결합), 공리 3(FSM 노름 차 = 광자 에너지), 공리 7(비용 변환)

공리 5: CAS Swap이 전자-정공 재결합을 수행. 순방향 바이어스로 캐리어 주입 ==> 재결합 확률 증가. 공리 3: FSM 노름 차이 $E_g$ = 방출 광자 에너지. $\lambda = hc/E_g$. 공리 7: 전기 비용 ==> 광 비용 변환. 내부 양자 효율 = 복사 재결합 비율.

적색 LED: GaAsP $E_g \sim 1.9\;\text{eV}$. 녹색: InGaN $\sim 2.3\;\text{eV}$. 청색: InGaN $\sim 2.6\;\text{eV}$. 백색 LED: 청색 + 형광체. OLED: 유기 FSM 노름 재료.

LED 효율: $\sim 50$~$70\%$ 내부 양자 효율. 수명: $\sim 50000\;\text{h}$. 발광 효율: $\sim 100$~$200\;\text{lm/W}$.

LED 방출 파장과 밴드갭 이론값 $< 2\%$ 정합.

전계발광, LED, OLED, 전자-정공 재결합, 직접 천이

LED 기술 50년 이상 실증. 노벨물리학상 2014(청색 LED).

녹색 갭(green gap) 문제의 FSM 노름 해석.

재대입 용도: 재대입 용도: H-849(광전지). H-843(다이오드). H-862(광통신)

5단계 재귀 대입: 전자-정공 재결합 Swap 비용에서 방출 파장 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

LED는 광전효과의 역과정이다. 광전지가 광자를 흡수해 노름 전이를 일으키는 반면, LED는 전자-정공 재결합이라는 Swap이 FSM 노름 차만큼의 비용을 광자로 되돌려 방출한다(공리 5: Swap = 재결합). 반야식 우항의 비용이 전기에서 광으로 변환된다(공리 7).

2단계. 노름 치환

(a) 치환하는 노름은 FSM 노름 차 = 광자 에너지 노름이다. 재결합 Swap이 방출하는 광자 에너지는 정확히 밴드갭 $E_g$(FSM 노름 차)이고(공리 3), 이것이 방출 광자의 진동수를 고정한다. (b) 이 노름을 택하는 까닭은 밴드갭 하나가 방출 파장을 단번에 정하기 때문이다. $E_g$가 정해지면 $\lambda = hc/E_g$로 파장이 닫힌다.

$E_{\text{photon}} = h\nu = E_g$
$\lambda = \dfrac{hc}{E_g}$
$E_{\text{photon}}$: 방출 광자 에너지 | $h$: 플랑크 상수 | $\nu$: 진동수 | $E_g$: 밴드갭 = FSM 노름 차 | $\lambda$: 방출 파장 | $c$: 광속

3단계. 상수 대입

h c       = 1240 eV·nm        광속·플랑크 곱
적색 E_g  = ~ 1.9 eV          GaAsP
청색 E_g  = ~ 2.6 eV          InGaN
파장-밴드갭 차 = < 2%

4단계. 도메인 변환

(a) 전계발광 방출 도메인(재결합 Swap 후 광자 방출)으로 변환한다. (b) 이 변환으로 보려는 것은 밴드갭 하나가 정하는 방출 파장이다. $E_g$를 $\lambda = hc/E_g$에 넣어 적색·청색 LED 파장을 산출한다.

$\lambda_{\text{적}} = \dfrac{1240}{1.9} \approx 653\ \text{nm}, \quad \lambda_{\text{청}} = \dfrac{1240}{2.6} \approx 477\ \text{nm}$

5단계. 발견

도출값: $\lambda_{\text{적}} \approx 653$ nm, $\lambda_{\text{청}} \approx 477$ nm
측정 정합: 방출 파장-밴드갭 이론값 차 $< 2\%$
측정 검증 대기: 녹색 갭 문제의 FSM 노름 해석

판정: 가설. 방출 파장이 밴드갭에서 2% 안으로 정합하지만, 녹색 갭(InGaN 녹색 효율 저하) 문제가 FSM 노름으로 닫히지 않아 발견 승격 전 단계다.

재결합 Swap이 노름 차를 광자로 되돌린다는 단일 규칙이 흡수(H-849)와 방출을 한 구조의 정·역으로 묶는다.
