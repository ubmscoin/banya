H-755: 정보 기하학 = CAS 상태 공간의 피셔 계량

등급: C

정보 기하학은 확률 분포 공간에 피셔 정보 계량을 부여한다. CAS 상태의 확률 분포가 다양체를 형성하고, 피셔 계량 $g_{ij}$ = CAS Compare의 민감도(비용 변화율).

공리 5(Compare = 확률 판정), 공리 4(비용 = 정보)

공리 5(Compare 확률 = 분포), 공리 4(비용 = 피셔 정보 원천), 공리 15(δ = 정보 최소 단위)

크라메르-라오 한계 = CAS 비용 추정 최소 분산. KL 발산 = CAS 상태 분포 비대칭 거리. 자연 기울기 = CAS 최적화 기하학적 방향. 지수족 = 충분 통계량.

열역학 피셔 정보 = 비열. 양자 피셔 정보 = 양자 크라메르-라오.

Amari(1985) 정보 기하학과 정합.

정보 기하학, 피셔 정보, KL 발산, 자연 기울기

CAS 비용 분포의 피셔 계량이 물리적 메트릭과 일치하는지 검증.

양자 정보 기하학(SLD)과 CAS Compare의 연결.

재대입 용도: 재대입 용도: H-750(텐서) 피셔 계량. H-757(혼돈) 정보 손실률

가설에서 멈춘 이유: 본 카드는 가설(분류 III)로 분류되어 다음 라운드로 미진행한 채 멈춰 있다. 정량 도출 식이 미작성된 상태이며, 구조 서술과 공리 근거 인용까지만 진행되었다. 식 자체가 도메인 변환에서 자연 도출되어야 하지만 현재는 명시적 식 형태가 본문에 등장하지 않는다. 잔여 과제 명시: 재대입 용도: 재대입 용도: H-750(텐서) 피셔 계량. 5단계 재귀 대입: Compare 비용 민감도에서 피셔 계량 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

정보 기하학은 CAS 상태의 확률 분포(공리 5 Compare 확률 판정)가 이루는 다양체에 부여하는 비용 곡률이다. Compare 비용이 분포 매개변수에 얼마나 민감하게 변하는가(공리 4 비용 = 정보)를 계량으로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 로그 우도 기울기의 분산 노름(피셔 계량)이다. (b) Compare 비용의 변화율 제곱 기대값이 분포 사이 거리의 곡률을 정하기 때문에 이 노름을 택한다(공리 15 δ = 정보 최소 단위). 따라서 CAS 상태 공간의 계량을 피셔 정보 $g_{ij}$로 치환한다.

$g_{ij} = \mathbb{E}\!\left[\dfrac{\partial \ln p}{\partial \theta^i}\dfrac{\partial \ln p}{\partial \theta^j}\right]$
$ds^2 = g_{ij}\,d\theta^i\,d\theta^j$
$p$: CAS Compare 확률 분포 (공리 5) | $\theta^i$: 분포 매개변수 | $g_{ij}$: 피셔 계량 = Compare 비용 민감도 | $ds^2$: 분포 간 거리 (공리 4)

3단계. 상수 대입

분포 p = Compare 확률 공리 5
계량 $g_{ij}$ = 로그 우도 기울기 분산
KL 발산 = 비대칭 거리
크라메르-라오 = $1/g_{ij}$ 최소 분산
정보 기하학 = Amari 1985

4단계. 도메인 변환

(a) CAS 확률 분포 도메인에서 정보 기하 다양체 도메인으로 변환한다. (b) 보려는 것은 추정 분산의 하한, 곧 크라메르-라오 한계다. 피셔 계량의 역수가 불편 추정량 분산의 하한을 정한다.

$\mathrm{Var}(\hat\theta) \ge \dfrac{1}{g_{\theta\theta}}$

5단계. 발견

도출: Compare 비용 민감도 = 피셔 계량 $g_{ij}$
대응: Amari 정보 기하학 (1985), 크라메르-라오 한계
구조 일치: 열역학 피셔 정보 = 비열

판정: 가설. Compare 비용의 분포 민감도가 피셔 계량과 구조적으로 대응하나 양자 피셔 정보(SLD)의 공리 도출이 미완이다. 비용이 매개변수에 민감한 정도가 곧 상태 공간의 곡률이다.
