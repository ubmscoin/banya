H-652. 셸 모형 = FSM 노름의 이산 에너지 준위

핵심 발견

H-652: 셸 모형 = FSM 노름의 이산 에너지 준위

$$V(r) = -V_0 f(r) + V_{\ell s}\,\vec\ell\cdot\vec s\;\frac{1}{r}\frac{df}{dr} \;\leftrightarrow\; \text{FSM 이산 준위 + lock 비트 결합}$$

등급: B

핵 셸 모형은 핵자가 평균 퍼텐셜 내 독립 궤도를 점유하며 스핀-궤도 결합이 준위를 분리한다. 반야에서 FSM(핵자)이 닫힌 구간 내 이산 에너지 준위에 배치되며, lock 비트(공리 9)의 $\ell\cdot s$ 결합이 준위 분열을 결정한다.

공리 3(FSM 이산 준위), 공리 9(lock 비트), H-648(마법수)

공리 3(FSM 닫힌 구간 ==> 이산 스펙트럼), 공리 9(lock 비트 = 스핀, $\vec\ell\cdot\vec s$ = lock 비트와 궤도 결합), 공리 5(CAS Swap = 파울리 배타 ==> 준위 채움). 우즈-색슨 퍼텐셜 $f(r) = [1+e^{(r-R)/a}]^{-1}$.

준위 순서: $1s_{1/2}, 1p_{3/2}, 1p_{1/2}, \ldots$ 스핀-궤도 분리가 마법수 결정. 단일 입자 상태 $|n\ell j m\rangle$ = FSM 이산 준위의 양자수. 셸 닫힘 ==> 비용 갭 극대 ==> 마법수.

O-16 첫 들뜸: $6.05\;\text{MeV}$. 스핀-궤도 분리: $1g_{9/2} - 1g_{7/2} \sim 6\;\text{MeV}$(Pb 근처).

마법수 핵의 단일 입자 에너지 실험과 $< 10\%$ 정합.

핵 셸 모형, 우즈-색슨 퍼텐셜, 스핀-궤도 결합, 마법수

전달 반응, 녹아웃 반응으로 단일 입자 상태 확인됨.

FSM 이산 준위에서 우즈-색슨 매개변수의 ab initio 도출.

재대입 용도: 재대입 용도: H-648(마법수). H-651(페르미 기체) 독립 입자. H-661(쌍 효과)

5단계 재귀 대입: lock 비트 결합 비용에서 셸 이산 준위 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

핵자는 평균 퍼텐셜 안에서 이산 궤도를 점유한다. 반야에서 FSM 닫힌 구간(공리 3)은 이산 스펙트럼을 낳고, 그 안을 CAS Swap 배타(공리 5)가 채운다. lock 비트(공리 9)와 궤도의 $\ell\cdot s$ 결합이 준위를 둘로 가른다.

2단계. 노름 치환

(a) 치환하는 노름은 우즈-색슨 닫힌 구간의 이산 준위 노름에 lock 비트 결합을 더한 것이다. FSM 닫힌 구간(공리 3)이 이산 준위를 정하고, lock 비트(공리 9) = 스핀이 궤도와 $\vec\ell\cdot\vec s$로 결합한다. (b) 이 결합이 준위 분열을 정하고 그 갭이 셸 닫힘 = 마법수(H-648)를 만들기 때문에 이 노름을 택한다.

$V(r) = -V_0\,f(r) + V_{\ell s}\,\vec\ell\cdot\vec s\;\dfrac{1}{r}\dfrac{df}{dr}$
$\Delta E_{\ell s} = V_{\ell s}\,\langle\vec\ell\cdot\vec s\rangle = V_{\ell s}\,\dfrac{2\ell+1}{2}$
$V_0$: 퍼텐셜 깊이 | $f(r)$: 우즈-색슨 형상 $[1+e^{(r-R)/a}]^{-1}$ | $V_{\ell s}$: lock 비트 결합 세기 | $\vec\ell\cdot\vec s$: 궤도-lock 비트 결합 | $\Delta E_{\ell s}$: 준위 분열 갭

3단계. 상수 대입

V_0       = 47 MeV          깊이 (H-651)
R         = r_0 A^(1/3)     r_0 = 1.27 fm
a         = 0.67 fm         표면 두께
j = l+1/2 / l-1/2           lock 비트 정렬/반정렬

4단계. 도메인 변환

(a) 핵 단일입자 준위 도메인으로 변환한다. (b) 보려는 것은 스핀-궤도 분열 갭, 곧 마법수를 가르는 에너지다. $1g$ 궤도($\ell=4$)에서 정렬·반정렬 준위 차이를 산출한다.

$\Delta E(1g_{9/2}\!-\!1g_{7/2}) = V_{\ell s}\,\dfrac{2\times 4 + 1}{2} \approx 6\;\text{MeV}$

5단계. 발견

도출값: 스핀-궤도 분열 $\approx 6\;\text{MeV}$ ($1g_{9/2}\!-\!1g_{7/2}$)
측정값: $^{16}\text{O}$ 첫 들뜸 $6.05\;\text{MeV}$ · Pb 근처 분열 $\sim 6\;\text{MeV}$
오차: $<10\%$

판정: 가설. lock 비트 $\ell\cdot s$ 결합이 마법수를 가르나, $V_{\ell s}$ 세기가 아직 공리 정수에서 도출되지 않아 forward chain이 닫히지 않았다.
