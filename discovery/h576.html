H-576: 페르미-디랙 분포 = CAS Swap 배타 원리

등급: A

페르미-디랙 분포 $f(\epsilon) = 1/(e^{(\epsilon-\mu)/k_BT} + 1)$는 CAS Swap의 배타 원리에서 기원한다. 동일 DATA 슬롯에 두 페르미온의 Swap이 금지되므로 각 상태의 점유수가 0 또는 1로 제한된다.

공리 4(CAS Swap 배타), 공리 3(DATA 슬롯), H-567(엔트로피)

공리 4(CAS Swap 배타 = 파울리 원리), 공리 3(DATA 슬롯 = 양자 상태), 공리 2(d-ring ==> 미시상태 열거)

페르미 에너지 $\epsilon_F$는 CAS Swap 배타에 의한 최고 점유 비용. 축퇴 페르미 가스(백색왜성, 중성자별)의 안정성이 CAS 배타에서 기원.

페르미-디랙 분포, 파울리 배타 원리, 페르미 에너지, 축퇴 가스

페르미 분포의 보편적 실험 확인. 파울리 원리 위반 탐색(VIP-2).

CAS Swap 배타의 스핀-통계 정리 대응. 반정수 스핀 ↔ 배타의 공리적 연결.

재대입 용도: 재대입 용도: H-577(BE 분포) 보손 대비. H-578(MB) 고전 극한. H-567(엔트로피) 미시상태 세기.

5단계 재귀 대입: CAS Swap 배타 비용에서 페르미-디랙 분포 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

한 DATA 슬롯의 점유는 CAS Swap이 그 슬롯에 쓰기를 시도할 때 치르는 비용이다. 공리 4(비용)는 비가역 쓰기를 비용으로 정하고, 공리 3(DATA는 이산)은 슬롯을 이산 단위로 못박는다. 같은 슬롯에 두 번째 Swap이 금지되면 점유수는 0 또는 1로 갇힌다.

2단계. 노름 치환

(a) 치환하는 노름은 공리 4 Swap 배타 노름이다. (b) 이 노름을 택하는 까닭은 대분배 함수에서 한 슬롯이 가질 수 있는 점유 상태가 비점유와 단일 점유 둘뿐으로 닫히기 때문이다. 슬롯당 합 $\sum_n e^{-n(\epsilon-\mu)/k_BT}$의 $n$이 $\{0,1\}$로 잘리면, 보손식의 무한 등비급수가 두 항 $1 + e^{-(\epsilon-\mu)/k_BT}$로 절단되어 분모 부호가 $+1$로 확정된다.

$\bar n = \dfrac{\sum_n n\,e^{-n(\epsilon-\mu)/k_BT}}{\sum_n e^{-n(\epsilon-\mu)/k_BT}},\quad n\in\{0,1\}$
$f(\epsilon) = \dfrac{1}{e^{(\epsilon-\mu)/k_BT} + 1}$
$f$: 점유수 | $n$: 슬롯 점유, Swap 배타로 $\{0,1\}$ | $\epsilon$: 상태 비용 | $\mu$: 화학퍼텐셜 | $+1$: 단일 점유 절단의 흔적

3단계. 상수 대입

n in {0, 1}                   CAS Swap 배타 (공리 4)
k_B = 1.380649e-23 J/K        CODATA 2018
sum_n = 1 + exp(-x)           x = (eps-mu)/(k_B T)

4단계. 도메인 변환

(a) 변환 도메인은 양자 통계의 점유수 분포다. (b) 보려는 것은 비용 $\epsilon$인 한 상태의 평균 점유수다. 절단된 두 항 합에 $\bar n$ 정의를 적용하면 분모의 $+1$이 그대로 살아남는다.

$\bar n = \dfrac{0\cdot 1 + 1\cdot e^{-x}}{1 + e^{-x}} = \dfrac{e^{-x}}{1+e^{-x}} = \dfrac{1}{e^{x}+1}$

5단계. 발견

도출식: $f(\epsilon) = 1/(e^{(\epsilon-\mu)/k_BT}+1)$
표준형: 페르미-디랙 분포 (1926)
일치: 분모 부호 $+1$ 정확

판정: 가설. 분모의 $+1$이 Swap 배타에 의한 점유 절단에서 자유 매개변수 없이 나온다. 잔여 과제는 스핀-통계 정리(반정수 스핀 $\leftrightarrow$ 배타)의 공리적 도출이다.
