H-485: 적색편이 = 비용 전파 경로의 RLU 감쇠

$$1 + z = \frac{a_0}{a_{\text{emit}}} = \frac{N_{\text{slot}}(t_0)}{N_{\text{slot}}(t_{\text{emit}})} = \frac{\lambda_{\text{obs}}}{\lambda_{\text{emit}}}$$

등급: B

적색편이는 광자가 전파되는 동안 RLU(공리 6)가 주소 공간을 해제하여 총 슬롯 수 $N_{\text{slot}}$이 증가하기 때문에 발생한다. 광자의 비용 단위가 팽창된 주소 공간에서 상대적으로 작아지는 것이다.

공리 6(RLU 해제 ==> 주소 공간 팽창), 공리 4(비용 전파), 공리 8(틱 단위 이산 진행)

공리 6(RLU 해제율 = 스케일 팩터 변화율), 공리 4(비용 $+1$/경계 ==> 파장 = 비용 단위), 공리 3(DATA 이산 ==> 슬롯 수 유한), 공리 8(틱마다 $N$ 갱신)

$z$는 연속이 아니라 이산: $\Delta z_{\min} = 1/N_{\text{slot}}$. 근거리 $z \ll 1$에서 허블 법칙 $v = H_0 d$로 근사. 고적색편이에서 비선형.

$z_{\text{eq}} = 3402$(D-43). $z_{\text{dec}} \approx 1090$. $z_{\text{reion}} \approx 7.7$(H-482). 모든 우주론적 적색편이가 $N_{\text{slot}}$ 비율로 환산.

적색편이-거리 관계 관측과 구조 정합. 초신성 Ia 허블 도표 $\Lambda$CDM 적합과 일치.

우주론적 적색편이, 허블 법칙, 스케일 팩터, 도플러 효과(근사)

이산 적색편이($\Delta z_{\min}$)의 관측 가능성. 톨만 표면 밝기 테스트. "피곤한 빛" 가설과의 구별(RLU는 팽창이지 에너지 손실이 아님).

$\Delta z_{\min}$의 수치 추정. 특이 적색편이(gravitational $z$)의 CAS 비용 해석.

5단계 재귀 대입: RLU 해제 슬롯 증가 비용에서 적색편이 $1+z$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

적색편이는 광자가 전파되는 동안 RLU가 주소 공간을 해제해(공리 6) 총 슬롯 수가 늘어나는 비용이다. 파장은 경계마다 $+1$의 비용 단위로 새겨지고(공리 4), 틱마다 슬롯 수 $N$이 갱신되며(공리 8), DATA가 이산이므로 슬롯 수는 유한하다(공리 3).

2단계. 노름 치환

치환하는 노름은 RLU 해제 슬롯 비율 노름이다. 광자의 비용 단위가 팽창된 주소 공간에서 상대적으로 작아져, 방출 시점과 관측 시점의 슬롯 수 비가 곧 파장 비가 되기 때문에 이 노름을 택한다. RLU 해제율이 스케일 팩터 변화율과 같으므로 슬롯 비율이 스케일 팩터 비율과 일치한다.

$1 + z = \dfrac{a_0}{a_{\text{emit}}} = \dfrac{N_{\text{slot}}(t_0)}{N_{\text{slot}}(t_{\text{emit}})}$
$1 + z = \dfrac{\lambda_{\text{obs}}}{\lambda_{\text{emit}}}$
$z$: 적색편이 | $a$: 스케일 팩터 | $N_{\text{slot}}$: RLU 총 슬롯 수 (공리 6) | $\lambda$: 파장 = 비용 단위 (공리 4)

3단계. 상수 대입

$z_{eq}$ = 3402 D-43
$z_{dec}$ = 1090
$z_{r}$ = 7.7 H-482
$\Delta$ $z_{min}$ = $1/N_{slot}$ 이산 최소 간격, 공리 3

4단계. 도메인 변환

bit7 발화비트 자기참조 루프 도메인(공리 8, 공리 15)으로 변환한다. 이 변환으로 보려는 것은 모든 우주론적 적색편이를 하나의 척도로 묶는 슬롯 비율, 곧 $1+z$다. 각 전이의 슬롯 비를 취해 그 값을 산출한다.

$1 + z_{\text{eq}} = \dfrac{N_{\text{slot}}(t_0)}{N_{\text{slot}}(t_{\text{eq}})} = 3403$

5단계. 발견

판정: 가설. 모든 우주론적 적색편이가 RLU 슬롯 수 비율로 환산되며 근거리 $z \ll 1$에서 허블 법칙 $v = H_0 d$로 근사된다. 이산 최소 간격 $\Delta z_{\min} = 1/N_{\text{slot}}$의 수치 추정이 잔여 과제다.
