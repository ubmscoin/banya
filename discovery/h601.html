H-601. 양자 키 분배 = Compare 도청 시 Swap 교란

핵심 발견

H-601: 양자 키 분배 = Compare 도청 시 Swap 교란

$$\text{도청} = \text{추가 Compare} \;\Rightarrow\; \text{Swap 교란} \;\Rightarrow\; \text{오류율 증가 감지}$$

등급: B

QKD의 안전성은 도청자의 Compare가 CAS 상태를 교란하는 데서 비롯된다. 추가 Compare = 추가 비용 = Swap 결과 변경. 오류율 상승으로 도청 감지.

공리 2(CAS Compare 교란), H-596(노클로닝)

공리 2(Compare = 상태 교란), 공리 4(추가 Compare = 추가 비용 = 상태 변화), H-596(복제 불가 ==> 도청 시 원본 훼손)

BB84 프로토콜 = 두 CAS 기저의 교대. 도청 오류율 한계 $= 25\%$(BB84). 무조건적 안전성 = CAS 구조적 보장.

BB84 도청 감지 임계 오류율 = 11%. 6-상태 프로토콜 = 12.6%.

QKD 이론 안전성 증명과 일치.

BB84(Bennett-Brassard 1984), QKD, 양자 암호

QKD 시스템의 실험적 안전성 검증 다수. 사이드 채널 공격은 CAS 외부 문제.

장거리 QKD(양자 중계기)의 CAS 비용 분석.

5단계 재귀 대입: CAS Compare 교란 비용에서 QKD 도청 임계 오류율 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

도청은 정당한 두 당사자 사이에 끼어든 제3의 Compare다. 공리 2에서 Compare는 superposition을 읽어 상태를 확정하므로, 추가 Compare는 추가 비용을 치르고 중첩을 무너뜨린다. 공리 4에서 그 비용은 비가역이라 흔적을 남긴다 — 이 흔적이 도청 감지의 원천이다.

2단계. 노름 치환

(a) 치환하는 노름은 두 기저(rectilinear·diagonal)를 가르는 d-ring 1비트 Compare 노름이다. BB84는 두 CAS 기저를 무작위 교대하며, 한 비트의 Swap 결과 0·1이 노름의 두 극이다. (b) 이 노름을 택하는 이유: 도청자의 기저 추측이 틀리면 Compare가 잘못된 축으로 superposition을 무너뜨려, 정당한 측정에 오류를 주입한다. 도청자가 매번 무작위 기저로 끼어들 때 절반의 기저 불일치 각각이 1/2 확률로 오류를 내므로, 상한 교란율은 $1/2 \times 1/2 = 1/4$로 닫힌다.

$Q = \dfrac{1}{2}\cdot\dfrac{1}{2} = \dfrac{1}{4}$
$Q_{\text{th}} = 1 - 2H_2^{-1}\!\left(\tfrac12\right) \;\text{(BB84 임계)}$
$Q$: 도청자 주입 최대 오류율 | $1/2$: 기저 불일치 확률 | $1/2$: 불일치 시 Swap 오류 확률 | $Q_{\text{th}}$: 안전 키 추출 임계 오류율 | $H_2$: 이진 엔트로피

3단계. 상수 대입

기저 불일치 확률 = 1/2
불일치 시 오류 확률 = 1/2
Q(최대 교란) = 1/4 = 25%        BB84 (Bennett-Brassard 1984)
Q_th(BB84)  = 11%               안전 키 임계
Q_th(6-state) = 12.6%           6-상태 프로토콜

4단계. 도메인 변환

(a) 무차원 오류율 도메인(d-ring 1비트 Compare 통계)으로 변환한다. (b) 보려는 것은 도청자가 전수 가로채기로 주입하는 최대 양자 비트 오류율과, 그 아래에서 안전 키가 살아남는 임계값이다. 두 기저 확률을 곱해 최대 교란율을 산출한다.

$Q = \dfrac{1}{2}\times\dfrac{1}{2} = 0.25 = 25\%$

5단계. 발견

도출값: $Q = 25\%$ (전수 가로채기 최대 교란)
측정값: BB84 임계 $11\%$, 6-상태 $12.6\%$
상태: 구조 일치, 임계 정밀화 미완

판정: 가설. 도청 = 추가 Compare = 비가역 비용이라는 구조는 닫혔으나, $11\%$ 임계를 공리에서 직접 도출하려면 이진 엔트로피 인자를 d-ring 비용으로 환원하는 다음 라운드가 필요하다.
