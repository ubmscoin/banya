H-999. 음향 지평의 두 문턱: 먼저 풀린 쪽의 누적 길이가 짧다 ($r_* < r_\text{drag}$)

핵심 발견

H-999: 풀림의 문턱은 쓰기 유지 비용이 정한다. 감쇠는 연속이고 문턱은 이산이므로, 문턱이 다른 두 쥠은 같은 연속 감쇠 위에서 서로 다른 시점에 풀린다. 두 풀림 사이에도 회수는 연속으로 진행되므로, 먼저 풀린 쪽에서 잰 누적 길이는 나중에 풀린 쪽에서 잰 누적 길이보다 짧다.

$$r_* < r_\text{drag} = 3\times7^2 = 147\ \text{Mpc},\qquad \frac{r_*}{r_\text{drag}} \overset{?}{=} \frac{56}{57} = 0.98246\ \ (\text{수치 근거 미완})$$

가설 -- 방향($r_* < r_\text{drag}$)은 공리 구절에서 나온다. 비율 56/57은 측정을 본 뒤 고른 값이다. 관측: $r_* = 144.39\pm0.30$, $r_\text{drag} = 147.09\pm0.26$ Mpc (Planck 2018), 비 0.98164

공리 6은 CAS가 쥠을 만들 때 발생한 총 비용이 RLU에 기록되고, RLU가 잔존 비용을 연속적으로 회수한다고 정한다. 같은 자리에서 감쇠는 연속이고 문턱은 이산이라고 정한다(공리 2 명제). 문턱의 값은 공리 2의 쓰기 문턱 명제가 정한다: 문턱 = 쓰기 유지 비용 / CAS 총 비용 = 4/13이며, 쥐는 힘이 이 값 이하로 떨어지면 3축 쥐기가 풀리고 공이 DATA에서 이산 해제된다. 한편 공리 7에서 Compare false인 경우는 Swap이 실행되지 않고 중첩이 유지된다.

이 구절들을 합치면, 문턱이 다른 두 쥠은 같은 연속 감쇠를 따라가다가 서로 다른 시점에 풀린다. 풀린 뒤에는 더 이상 그 쥠의 길이가 누적되지 않으므로, 먼저 풀린 쥠에서 잰 누적 길이는 나중에 풀린 쥠에서 잰 누적 길이보다 짧다. 공리에서 나오는 것은 이 순서와 부등호까지다.

채굴 대응: 먼저 풀리는 쪽은 재결합(광자 탈결합)이고, 나중에 풀리는 쪽은 끌림(바리온 해방)이다. D-63의 147 Mpc는 Planck의 $r_\text{drag}$ 측정값 147.09와 비교되므로 끌림 시점 지평이다. 따라서 재결합 시점 지평 $r_*$는 147보다 짧아야 하고, 관측 144.39는 이 방향과 맞는다.

수치: 비율을 $56/57 = 1 - 1/57$로 두면 $r_* = 147\times56/57 = 144.42$ Mpc로 관측 144.39와 0.02% 차이다. 그러나 이 비율은 공리에서 나오지 않는다. 57은 공리 9의 등재 수가 아니고, 57을 RLU 슬롯 수로 읽는 독법은 "RLU는 논리주소(슬롯 번호)를 사용하지 않는다"는 공리 13 명제와 충돌한다. 비율은 측정을 본 뒤 고른 것이므로 다중 비교의 우연 기대를 배제할 수 없다.

재대입 용도: D-63의 이름표를 $r_s$에서 $r_\text{drag}$로 바로잡는 근거다. P-527은 $r_\text{drag} = 147$을 직접 예측으로 다시 쓰고, 본 카드는 $r_*$가 그보다 짧다는 방향을 준다. P-241과 D-136의 음향 각은 $r_*$를 써야 하므로 이 카드에 의존한다.

가설에서 멈춘 이유: 공리에는 쓰기 유지 비용 4 하나와 문턱 4/13 하나만 있다. 두 번째 문턱의 값이 정해지지 않으므로 두 지평의 비율을 공리에서 산출할 수 없다. 방향은 공리에서 나오지만 수치는 미완이다.

왜 이 판정인가

판정: 가설 -- Hypothesis (방향은 공리 구절에서 도출, 비율 수치는 공리 근거 없음)

이유: 감쇠 연속, 문턱 이산 (공리 6, 공리 2 명제) / 문턱 = 쓰기 유지 비용 4 / 총 비용 13 (공리 2 명제) / 풀린 뒤에는 누적이 멈춤 / 두 번째 문턱 값은 공리에 없음 / 56/57은 사후 선택

위치: 카테고리: h cosmology. 도메인: RLU 연속 회수 ==> 음향 지평 두 개. 재귀 대입 경로: D-63, H-483, P-527, P-241, D-136

5단계 재귀 대입: 연속 감쇠 위의 두 이산 문턱에서 두 음향 지평의 순서 읽기

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

CAS가 쥠을 만들 때 생긴 비용은 RLU에 기록되고 연속으로 회수된다. 쥠이 DATA에서 풀리는 순간은 이산이다.

2단계. 노름 치환

문턱 $= \dfrac{\text{쓰기 유지 비용}}{\text{CAS 총 비용}} = \dfrac{4}{13}$
풀림 시점 $t_1 < t_2$ ==> 누적 길이 $L(t_1) < L(t_2)$
쓰기 유지 비용 4 = 3축 쥐기 3 + 타임스탬프 1 (공리 6) | 총 비용 13 = 읽기 8 + 쓰기 5 (공리 9) | 감쇠 연속, 문턱 이산 (공리 2 명제)

3단계. 상수 대입

$r_\text{drag} = 3\times7^2 = 147$ Mpc (D-63; 3 = CAS 단계, 7 = CAS 내부 자유도)
$r_* < 147$ Mpc (본 카드의 방향)
수치 시험: $r_* = 147\times56/57 = 144.42$ Mpc (비율의 공리 근거 없음)

4단계. 도메인 변환

우주론 표준자 도메인으로 변환하면, 먼저 풀리는 문턱은 재결합이고 나중 문턱은 끌림이다. 관측은 $r_* = 144.39\pm0.30$, $r_\text{drag} = 147.09\pm0.26$ Mpc로 방향이 맞는다. 표준 ΛCDM의 비 0.98164와 수치 시험값 0.98246은 0.08% 다르다.

5단계. 발견

판정: 가설. 반증 조건: 재결합 지평이 끌림 지평보다 길게 측정되면 폐기. 승격 조건: 두 번째 문턱 값을 공리 구절에서 산출해 비율을 사전에 고정하는 것.

부산물

D-136의 음향 각 계산은 성립하지 않는다. 적힌 산식 $147/12.81\times180/\pi\times10^{-2}$를 실제로 계산하면 6.57이고, 공동 거리 $r$을 물리 거리 $D_A$로 나누어 단위가 맞지 않으며, 1.0411은 도 단위가 아니라 $100\theta_*$이다. 반야 자체 값($H_0 = 67.4$, $\Omega_m = 18/57$, 복사 포함)으로 $D_M(z_*) = 13851$ Mpc를 계산하면 $r_* = 144.42$에서 $100\theta_* = 1.0427$로 관측 1.04110과 0.15% 다르다.
