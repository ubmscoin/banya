H-715. 광자 반묶음 = FSM 노름 0 엔티티의 반상관

핵심 발견

H-715: 광자 반묶음 = FSM 노름 0 엔티티의 반상관

$$g^{(2)}(0) < 1 \;\leftrightarrow\; \text{FSM 노름 0 엔티티(광자)의 반묶음 상관}$$

등급: B

광자 반묶음은 단일 광자원에서 두 광자가 동시에 도착하지 않는($g^{(2)}(0) < 1$) 비고전적 상관이다. FSM 노름 0 엔티티(광자)의 양자 성질. $g^{(2)}(0) = 0$은 완전 단일 광자.

공리 3(FSM 노름), 공리 4(CAS 비용 양자)

공리 3(FSM 노름 0 = 광자), 공리 4(단일 CAS 비용 양자 방출 = 한 번에 하나), 공리 9(양자 상태의 비고전 상관)

HBT 실험: $g^{(2)}(\tau)$ 측정. 열광: $g^{(2)}(0) = 2$(묶음). 레이저: $g^{(2)}(0) = 1$(포아송). 단일 광자: $g^{(2)}(0) \to 0$. 양자 점, NV 센터 = 단일 광자원.

양자 점 단일 광자: $g^{(2)}(0) < 0.01$. NV 센터: $g^{(2)}(0) \approx 0.1$.

단일 광자 실험과 정합.

광자 반묶음, $g^{(2)}$ 상관 함수, HBT 실험, 단일 광자원

HBT 실험(1956), 양자 점/NV 센터 단일 광자로 검증.

FSM 노름 0 엔티티의 반묶음 통계와 공리 3의 정량적 연결.

5단계 재귀 대입: FSM 노름 0 단일 방출에서 반묶음 $g^{(2)}(0)$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

광자 반묶음은 단일 광자원에서 두 광자가 동시에 도착하지 않는 비고전 상관이다. 광자는 FSM 노름 0 엔티티(공리 3)이고, 단일 CAS 비용 양자가 한 번에 하나씩만 방출되는 비용 구조(공리 4)로 이 반상관을 읽는다.

2단계. 노름 치환

치환하는 노름은 단일 방출 2차 상관 노름이다. 한 방출원이 한 번에 하나의 비용 양자만 내보내면 동시(지연 0) 검출 확률이 떨어져 $g^{(2)}(0)<1$이 되기 때문에 이 노름을 택한다. 따라서 반묶음을 0지연 정규화 상관으로 치환한다.

$g^{(2)}(0) = \dfrac{\langle n(n-1)\rangle}{\langle n\rangle^2}$
$g^{(2)}_{\text{single}}(0) = 1 - \dfrac{1}{N}$
$g^{(2)}(0)$: 0지연 2차 상관 | $n$: 검출 양자 수 | $N$: 동시 방출 가능 엔티티 수 | $N=1$이면 $g^{(2)}(0)=0$ (완전 단일)

3단계. 상수 대입

thermal      g2(0) = 2       묶음(보스 통계)
laser        g2(0) = 1       포아송
QD single    g2(0) < 0.01    양자 점 측정
NV center    g2(0) = 0.1     NV 센터 측정

4단계. 도메인 변환

전자기 결합 도메인으로 변환한다. 이 변환으로 보려는 것은 단일($N=1$) 방출원의 0지연 상관, 곧 완전 단일 광자의 반묶음 극한이다. $N=1$을 위 식에 대입해 그 값을 산출한다.

$g^{(2)}_{\text{single}}(0) = 1 - \dfrac{1}{1} = 0$

5단계. 발견

도출값: $g^{(2)}(0) = 0$ ($N=1$ 단일 방출 극한)
측정값: 양자 점 $g^{(2)}(0)<0.01$, NV 센터 $\approx 0.1$
상태: 단일 광자 실험과 정합, $N$의 FSM 노름 0 정량 연결 미닫힘

판정: 가설. $g^{(2)}(0)<1$ 경계는 단일 방출 비용 구조에서 직접 따라오지만, 방출 엔티티 수 $N$을 FSM 노름 0(공리 3)에서 닫는 단계가 남아 있다.

통찰: 레이저 1을 경계로 위쪽 묶음(열광 2)과 아래쪽 반묶음(단일 0)이 갈리며, 단일 방출만 $1-1/N$로 1 아래로 내려간다.
