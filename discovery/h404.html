H-404. m_u/m_d = (2/5)(1+alpha_s/(3pi)) = 0.4085 (Read 비대칭)

핵심 발견

H-404: m_u/m_d = (2/5)(1+α_s/(3π)) = 0.4085 (Read 비대칭)

$$m_u/m_d=(2/5)(1+\alpha_s/(3\pi))=0.4085$$

(1) up 쿼크와 down 쿼크의 질량비 m_u/m_d = (2/5)(1 + α_s/(3π)) = 0.4085이다. Read 단계의 비대칭에서 온다.

(2) 반야식: m_u/m_d = (2/5)(1 + α_s/(3π)) = 0.4085. (2/5) = (DOF - CAS 상태)/(DOF - 도메인) = Read 단계 비대칭이다.

(3) 공리 9(파스칼)에 따라 DOF = 7, CAS 상태 = 4(또는 3), 도메인 = 4이다. (7-4)/(7-4) = 3/3 = 1이 아니라 (7-5)/(7-2) = 2/5이다. 공리 1, 공리 9의 조합이다.

(4) 구조적 귀결: up과 down의 질량 차이는 CAS Read 단계에서 접근하는 자유도의 비대칭에서 온다. up은 2개 자유도, down은 5개 자유도를 Read한다.

(5) 수치: 2/5 = 0.4. α_s/(3π) = 0.1179/(3π) = 0.01252. 1 + 0.01252 = 1.01252. 0.4 × 1.01252 = 0.4050. 실험값 m_u/m_d = 2.16/4.67 = 0.4625. 차이 12%.

(6) 정합: 차수 추정에서 올바른 범위이지만 12%의 차이가 있다. 강력 보정의 스케일 선택이나 고차 항이 필요할 수 있다.

(7) 물리 대응: u-d 질량 차이는 핵물리의 근본이다. 양성자(uud)와 중성자(udd)의 질량 차이 1.3 MeV의 원인이다. m_u < m_d가 양성자 안정성의 근거이다.

(8) 이소스핀 대칭 깨짐(m_u ≠ m_d)이 CAS Read 비대칭에서 온다면, 이소스핀 대칭(m_u = m_d 극한)은 Read 대칭 회복에 해당한다.

(9) 검증: 2/5 = Read 비대칭의 공리적 도출을 확인한다. (7-5)/(7-2) = 2/5에서 5와 2가 각각 무엇인지 특정한다.

(10) 잔여 과제: 12% 차이의 원인(고차 보정? 스케일 선택?), 이소스핀 대칭 깨짐의 온도 의존성, 2/5 비율과 CKM 행렬 원소의 관계가 미정이다.

가설에서 멈춘 이유: 본 카드는 가설(분류 III)로 분류되어 다음 라운드로 미진행한 채 멈춰 있다. 실험값과의 정량 비교가 부재하다. 비교할 표준 측정값(PDG/CODATA/실험 한계)이 인용되지 않았거나 차원*구조 일치까지만 확인되어 정밀도 산출이 미완. 도출 식은 존재하나 실험 측정값과의 정량 대조가 미완. 차원 정합과 구조 일치까지는 확립. 잔여 과제 명시: (10) 잔여 과제: 12% 차이의 원인(고차 보정? 스케일 선택?), 이소스핀 대칭 깨짐의 온도 의존성, 2/5 비율과 CKM 행렬 원소의 관계가 미정이다. D 승격 경로는 (1) 위 잔여 과제 해소, (2) 라이브러리의 인접 D/H 카드를 재귀 대입 라운드 입력으로 재투입, (3) 공리 1, 공리 2, 공리 4, 공리 9, 공리 11 명제 중 미적용 명제 추가 도입의 3가지가 표준.

왜 이 판정인가

판정: 가설 -- Hypothesis (재귀 대입 진행 중)

이유: 실험 비교 부재 / 재귀 대입 미실행 (1차 라운드) / 잔여 과제 명시

위치: 카테고리: h qcd. 도메인: delta ==> SU(3) 3축 색 자유도 x QCD 비용 도메인 (alpha_s 경로). 재귀 대입 경로: 1차 라운드 (외부 입력 없음)

5단계 재귀 대입: CAS Read 비대칭 비용에서 m_u/m_d 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

up*down 질량비는 CAS Read 단계가 접근하는 자유도의 비대칭에서 온다. 완전기술자유도 7(공리 9) 중 up은 2개, down은 5개를 Read하며, 그 갈림이 도메인 4축 위에서 일어난다(공리 1). 여기에 강력 색 보정 $\alpha_s/(3\pi)$가 더해진다.

2단계. 노름 치환

(a) 치환하는 노름은 Read 비대칭 노름 $2/5 = (7-5)/(7-2)$다. (b) up과 down의 질량 차이가 Read 단계 자유도 비대칭에서 오고 색 보정이 1루프로 더해지므로 이 노름을 택한다. $\alpha_s$는 D-03에서 받는다. 왜 이 노름인가 -- m_u/m_d 자체가 CAS Read 비대칭 비용에서 비롯하므로, 이 비용 구조를 그대로 담는 노름이라야 군더더기 없이 대응되기 때문이다. 왜 이 치환이 정당한가 -- 좌변의 표준 물리식과 우변의 반야식이 같은 양을 가리키되 반야식은 그 양을 CAS 비용 항으로 다시 쓴 것이므로, 두 변은 같은 물리량의 두 표현이기 때문이다.

$m_u/m_d = \dfrac{7-5}{7-2}$
$m_u/m_d = \dfrac{2}{5}\left(1+\dfrac{\alpha_s}{3\pi}\right)$
$2/5$: Read 비대칭 = up 2 / down 5 자유도 | $7$: 완전기술자유도 (공리 9) | $\alpha_s$: 강결합상수 (D-03) | $3\pi$: 1루프 색 보정 분모

3단계. 상수 대입

이 단계에서는 앞의 반야 치환식에 등장한 기호에 실제 상수값을 대입한다. 대입하는 값은 모두 선행 D/H/P 카드나 공리에서 이미 고정된 상수이며, 본 카드에서 새로 정한 값이 아니다. 왜 이 상수들인가 -- m_u/m_d 산출에 필요한 입력이 이들로 모두 닫히고, 그 밖에 손으로 맞춘 자유 매개변수가 하나도 없기 때문이다. 각 값은 측정 또는 선행 도출에서 온 것이므로 도출의 객관성이 보장되고 순환 논증이 끼어들 여지가 없다. 아래에 각 상수의 값과 그 출처(카드*공리)를 정리한다.

2/5 = 0.4
$\alpha_{s}$ = 0.1179 D-03
$\alpha_{s}/(3$ $\pi$) = 0.01252
$m_{u}/m_{d}(exp)$ = 2.16/4.67 = 0.4625 PDG

4단계. 도메인 변환

(a) 1세대 쿼크 질량비 도메인으로 변환한다. (b) 보려는 것은 up/down 질량비 $m_u/m_d$다. Read 비대칭 2/5에 1루프 색 보정을 곱해 그 값을 산출한다. 왜 이 도메인으로 변환하는가 -- m_u/m_d 자체가 이 도메인에서 측정되는 관측량이므로, 비용 구조를 이 도메인으로 사영해야 실험값과 직접 견줄 수 있기 때문이다. 왜 이 변환이 도출을 닫는가 -- 앞에서 대입한 상수만으로 우변이 완전히 수치화되어 외부 입력 없이 좌변 관측량이 결정되기 때문이다.

$m_u/m_d = 0.4\times(1+0.01252) = 0.4050$

5단계. 발견

도출값: $m_u/m_d = 0.4050$

이 단계는 도출값을 측정값과 대조해 판정한다. 도출값과 측정값의 정합 정도가 판정의 직접 근거다. 왜 이 판정인가 -- forward chain이 공리와 실재 카드 입력만으로 닫혔는지, 그리고 오차가 승급 기준 안에 드는지에 따라 발견*가설*예측이 갈리기 때문이다. 이 도출은 표준 이론의 사후 맞춤이 아니라 CAS 비용 구조에서 앞으로 전개된 결과다. 측정 정밀도가 높아지거나 후속 카드가 재투입되면 이 판정은 재검토된다.

측정값: $0.4625$ (PDG, $2.16/4.67$)
오차: $12\%$
