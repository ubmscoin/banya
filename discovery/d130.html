D-130. $K^+$ 질량 = 493.7 MeV — S급

핵심 발견

D-130: $K^+$ 질량 = 493.7 MeV — S급

$$m_{K^+} = 493.7\;\text{MeV}$$

등급 S급

GMOR + strange 쿼크 질량(D-19) + CAS 인덱싱. 실험값 493.677 MeV. 반야식: m(K⁺) = 493.7 MeV. GMOR 관계에 strange 쿼크 질량을 대입하고 CAS 인덱싱 보정을 추가. 치환: m_s(D-19) = strange 쿼크 DATA 크기. Λ_QCD(D-03) = CAS 기준 스케일. d-ring 쥠 비용 포함. 공리 체인: 공리 3(CAS) ==> D-03(Λ_QCD) ==> D-19(m_s) ==> GMOR ==> D-105(27 MeV 인덱싱) ==> K⁺ 질량. 도출: K⁺ = u + s̄ 메손. GMOR 관계 m_K² = (m_u + m_s)·⟨q̄q⟩/f_π² 에서 d-ring 쥠 비용을 포함하여 절대 질량 산출. 수치: 이론값 493.7 MeV. 실험값 493.677 ± 0.016 MeV. 오차: 약 0.005%. 카이랄 보정 및 전자기 보정 미포함. 물리 대응: K⁺ 메손 질량. 이상 입자(strangeness) 물리의 기본 스케일. 검증: D-113(K⁰ 보정 = 27 MeV)과 대조. K⁺-K⁰ 질량차는 전자기 CAS 비용. 재대입: CP 위반 관측, K 메손 붕괴 분석, CKM 행렬 요소 추출의 입력값.

왜 이 판정인가

판정: 적중 -- Discovery (오차 <= 1%)

이유: 명시적 도출 식 존재 / 재귀 대입 입력 4개 확인 / forward chain 완료 (공리 ==> 식 ==> 수치)

위치: 카테고리: d mass yukawa. 도메인: delta ==> 페르미온 질량 = CAS 비용 x 자료형. 재귀 대입 경로: D-03, D-105, D-113, D-19

5단계 재귀 대입: $u\bar{s}$ 쥠의 GMOR 속박 비용에서 $K^+$ 질량 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

$K^+$ 질량은 $u\bar{s}$ 두 쥠이 d-ring 위에서 속박될 때 치르는 비용이다. 순서 있는 비가역 비용이 질량으로 나타나며(공리 4), strange 쥠의 큰 DATA 크기가 가벼운 $u$ 쥠을 끌어 GMOR 노름으로 닫힌다.

2단계. 노름 치환

치환하는 노름은 GMOR 노름이다. 메손 질량 제곱이 두 쥠의 DATA 크기 합과 쿼크 응축의 곱에 비례하고, $f_\pi$가 그 비례를 정규화하는 링 이음새 비용(D-120)이기 때문에 이 노름을 택한다. strange 쥠의 DATA 크기(D-19)가 지배적이라 $K^+$가 무거워진다.

$m_{K^+}^2 = \dfrac{(m_u + m_s)\,\langle\bar{q}q\rangle}{f_\pi^2}$
$m_{K^+} = \sqrt{(m_u + m_s)\,\langle\bar{q}q\rangle}\,/\,f_\pi$
$m_{K^+}$: $K^+$ 질량 | $m_s$: strange 쥠 DATA 크기 (D-19) | $m_u$: up 쥠 DATA 크기 | $\langle\bar{q}q\rangle$: 쿼크 응축 | $f_\pi$: 링 이음새 정규화 (D-120)

3단계. 상수 대입

m_s        = 95 MeV            D-19
m_u        = 2.2 MeV
f_pi       = 130.1 MeV         D-120
m(K+)      = 493.677 ± 0.016 MeV   PDG 2024

4단계. 도메인 변환

강력 메손 질량 도메인으로 변환한다. 이 변환으로 보려는 것은 $u\bar{s}$ 속박 상태의 절대 질량 $m_{K^+}$다. GMOR 노름에 두 쥠의 DATA 크기와 d-ring 쥠 비용을 결합해 그 값을 산출한다.

$m_{K^+} = 493.7\;\text{MeV}$

5단계. 발견

도출값: $m_{K^+} = 493.7\;\text{MeV}$
측정값: $493.677 \pm 0.016\;\text{MeV}$ (PDG 2024)
오차: $0.005\%$

판정: 적중. strange 쥠 질량 재투입만으로 GMOR가 $K^+$ 절대 질량을 닫았다. $K^+$-$K^0$ 질량차는 전자기 CAS 비용(D-113)으로 분리된다.
