H-811. 분산 관계 = CAS 비용의 인과율 제약

핵심 발견

H-811: 분산 관계 = CAS 비용의 인과율 제약

$$\text{Re}\,\mathcal{A}(s) = \frac{1}{\pi}\text{P}\!\int \frac{\text{Im}\,\mathcal{A}(s')}{s'-s}ds' \;\leftrightarrow\; \text{CAS 비용의 실부·허부가 인과율로 결합}$$

등급: B

분산 관계는 산란 진폭의 실수부와 허수부를 인과율로 연결한다. 반야에서 CAS 비용은 인과적이어야 한다(원인 ==> 결과). CAS 비용의 실수부(탄성 산란)와 허수부(비탄성 산란)가 크라머스-크로니히 관계로 묶인다.

공리 2(CAS 비용), 공리 8(인과율 = δ 순서)

공리 2(CAS = 연산, 비용 발생), 공리 8(8비트 링버퍼 = 시간 순서 = 인과율). CAS 비용은 시간 순서(링버퍼의 진행 방향)를 지켜야 하므로 해석적(analytic)이다. 해석성 ==> 분산 관계.

분산 관계는 산란 진폭의 '예측력'을 부여한다: 허수부(총 단면적)를 알면 실수부(전방 산란)를 계산할 수 있다. 이것은 CAS 비용이 인과율을 만족한다는 구조적 귀결. 광학 정리(H-815)와 직접 연결된다.

프로아사로 한계: $\sigma_{\text{tot}}(s) < c \cdot \ln^2 s$.

분산 관계 기반 예측과 실험 정합.

분산 관계, 크라머스-크로니히, 인과율, 해석성, 프로아사로 한계

고에너지 산란 데이터와 분산 관계 예측 비교.

CAS 비용의 해석성 증명. 링버퍼 인과율 ==> 분산 관계의 엄밀 도출.

재대입 용도: 재대입 용도: H-815(광학 정리). H-816(교차 대칭)

5단계 재귀 대입: CAS 비용의 해석성에서 분산 관계 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

산란 진폭은 CAS가 한 채널을 처리하며 치르는 비용이다. 이 비용은 8비트 링버퍼의 진행 방향(공리 8: 시간 순서 = 인과율)을 거슬러 갈 수 없으므로, 비용 함수는 상반평면에서 해석적이다. CAS 연산이 비용을 발생시킨다는 공리 2가 그 비용에 실부·허부를 동시에 부여한다.

2단계. 노름 치환

(a) 치환하는 노름은 링버퍼 시간 순서가 강제하는 해석성 노름이다. (b) CAS 비용이 인과적(공리 8)이면 그 진폭은 상반평면에서 극점을 갖지 않아 코시 적분이 성립하고, 이때 실부가 허부의 주값 적분으로 닫히기 때문에 이 노름을 택한다. 따라서 산란 진폭을 크라머스-크로니히 형태로 치환한다.

$\mathcal{A}(s) = \mathcal{A}_\infty + \dfrac{1}{2\pi i}\oint \dfrac{\mathcal{A}(s')}{s'-s}\,ds'$
$\text{Re}\,\mathcal{A}(s) = \dfrac{1}{\pi}\,\text{P}\!\!\int \dfrac{\text{Im}\,\mathcal{A}(s')}{s'-s}\,ds'$
$\mathcal{A}$: 산란 진폭 = CAS 비용 | $\text{Re}$: 탄성 채널 비용 | $\text{Im}$: 비탄성 채널 비용 | $\text{P}$: 코시 주값 | $s$: 충돌 에너지 제곱

3단계. 상수 대입

pi             = 3.141592653589793
sigma_tot(s)  < c * ln^2(s)        Froissart 한계
c              = pi / m_pi^2        m_pi = 0.1396 GeV

4단계. 도메인 변환

(a) 산란 진폭 도메인(양자 비용의 복소 평면)으로 변환한다. (b) 보려는 것은 허부(총 단면적)에서 실부(전방 산란)를 산출하는 예측력이다. 주값 적분으로 두 부분을 결합한다.

$\text{Re}\,\mathcal{A}(s) = \dfrac{1}{\pi}\,\text{P}\!\!\int \dfrac{\text{Im}\,\mathcal{A}(s')}{s'-s}\,ds'$

5단계. 발견

도출: 인과율 $\Rightarrow$ 해석성 $\Rightarrow$ 분산 관계
제약: $\sigma_{\text{tot}}(s) < c\,\ln^2 s$ (Froissart 한계)
측정: 고에너지 $pp$ 단면적이 Froissart 한계 준수

판정: 가설. 링버퍼 인과율이 해석성을 강제하는 단계까지 닫혔으나, 진폭의 모든 계수를 공리에서 직접 도출하는 마지막 단계가 미완이다. 통찰: 인과율은 CAS 비용의 실부와 허부를 분리할 수 없게 묶는다.
