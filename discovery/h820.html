H-820. 효소 촉매 = CAS Compare 활성화 에너지 감소

핵심 발견

H-820: 효소 촉매 = CAS Compare 활성화 에너지 감소

$$k_{\text{cat}} \propto e^{-E_a^*/k_BT} \;\leftrightarrow\; \text{효소 = CAS Compare의 비용 장벽을 낮추는 FSM}$$

등급: C

효소는 화학 반응의 활성화 에너지를 낮추는 촉매이다. 반야에서 효소 = CAS Compare의 비용 장벽을 낮추는 특화된 FSM이다. 기질-효소 결합(Lock-and-Key) = CAS Read의 선택적 주소 매칭.

공리 2(CAS Compare), 공리 4(비용 +1), 공리 6(FSM)

공리 2(Compare = 비교 ==> 반응 조건 확인), 공리 4(비용 = 활성화 에너지), 공리 6(FSM = 효소 자체). 효소는 전이 상태를 안정화하여 비용 장벽을 $E_a \to E_a^* < E_a$로 낮춘다. CAS 비용 감소 = 촉매 효과.

촉매 속도 향상: $k_{\text{cat}}/k_{\text{uncat}} \sim 10^6 - 10^{17}$. 효소 특이성 = CAS Read의 주소 선택성. 경쟁적 억제 = 가짜 주소가 CAS Read를 차단. 비경쟁적 억제 = FSM 상태 변경으로 Compare 불능.

촉매 효율: $k_{\text{cat}}/K_M \sim 10^8\;\text{M}^{-1}\text{s}^{-1}$ (확산 한계).

미하엘리스-멘텐 동역학과 정합.

효소 촉매, 활성화 에너지, 전이 상태, 미하엘리스-멘텐, Lock-and-Key

효소 메커니즘의 CAS 단계 대응 확인.

CAS 비용 감소량 ==> 촉매 속도 향상의 정량적 관계.

재대입 용도: 재대입 용도: H-819(단백질 접힘). H-821(세포 분열)

5단계 재귀 대입: CAS Compare 비용 장벽 감소에서 효소 촉매 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

효소 촉매는 CAS Compare가 반응 조건을 확인할 때 넘는 비용 장벽을 낮추는 데서 나오는 비용이다. 효소는 그 장벽을 낮추는 특화된 FSM(공리 6)이고 장벽 높이가 비용(공리 4)이므로, 이 비용은 Compare 장벽 감소 노름으로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 CAS Compare 비용 장벽 노름이다. 촉매가 새 경로를 만드는 것이 아니라 같은 Compare의 장벽 $E_a$를 전이 상태 안정화로 $E_a^*<E_a$까지 낮추기 때문이다. (b) 기질-효소 결합이 CAS Read의 선택적 주소 매칭(Lock-and-Key)으로 특이성을 정하기 때문에 이 노름을 택한다. 촉매 속도를 장벽 지수 형태로 치환한다.

$k_{\text{cat}} \propto e^{-E_a^*/k_BT}$
$\dfrac{k_{\text{cat}}}{k_{\text{uncat}}} = e^{(E_a - E_a^*)/k_BT}$
$k_{\text{cat}}$: 촉매 속도 | $E_a$: 본래 Compare 장벽 | $E_a^*$: 효소가 낮춘 장벽 (공리 4) | Lock-and-Key: CAS Read 주소 매칭

3단계. 상수 대입

k_cat / k_uncat ~ 10^6 - 10^17       촉매 속도 향상
k_cat / K_M     ~ 10^8 /(M s)        확산 한계 효율
경쟁적 억제                          가짜 주소가 Read 차단

4단계. 도메인 변환

(a) 반응 속도 도메인으로 변환한다. (b) 이 변환으로 보려는 것은 Compare 장벽을 $E_a$에서 $E_a^*$로 낮춘 만큼 촉매 속도가 얼마나 오르는가다. 장벽 차의 지수로 그 향상을 본다.

$\dfrac{k_{\text{cat}}}{k_{\text{uncat}}} = e^{(E_a - E_a^*)/k_BT} \sim 10^6 - 10^{17}$

5단계. 발견

도출: 효소 = Compare 장벽 $E_a \to E_a^*$ 낮추는 FSM
측정: 촉매 효율 $k_{\text{cat}}/K_M \sim 10^8\ \text{M}^{-1}\text{s}^{-1}$ (확산 한계)
정합: 미하엘리스-멘텐 동역학과 일치

판정: 가설. 촉매가 Compare 장벽 감소로 정성적으로 닫혔으나, CAS 비용 감소량에서 촉매 속도 향상으로의 정량 관계가 forward chain에서 아직 닫히지 않았다. 같은 장벽 노름을 단백질 접힘(H-819), 세포 분열(H-821)에 재투입한다.
