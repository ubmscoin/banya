H-660. 핵 사중극 모멘트 = 도메인 비트의 비구면 분포

핵심 발견

H-660: 핵 사중극 모멘트 = 도메인 비트의 비구면 분포

$$Q = \frac{1}{e}\int \rho(r)(3z^2 - r^2)\,d^3r \;\leftrightarrow\; \text{도메인 비트 비구면 분포}$$

등급: C

핵 사중극 모멘트는 핵 전하 분포의 비구면 변형도를 나타낸다. 반야에서 도메인 비트(공리 1)가 3축에 비등방으로 분포하면 사중극 모멘트 $Q \neq 0$이며, FSM 집합의 비구면 비용 분포를 반영한다.

공리 1(도메인 4축), 공리 3(FSM 분포), H-653(집단 운동)

공리 1(도메인 3공간축 ==> 비등방 분포 가능), 공리 3(FSM 노름 분포 = 전하 밀도 $\rho(r)$), 공리 4(비구면 변형의 비용 = 변형 에너지). 변형 매개변수 $\beta_2$: 장타원($Q > 0$), 편타원($Q < 0$).

구형 핵(마법수): $Q \approx 0$. 변형 핵(희토류, 악티노이드): $|Q| \sim 수\;\text{barn}$. 닫힌 껍질 ± 수 핵자: 단일 입자 $Q$ ≪ 집단 $Q$. 사중극 변형 = 회전 띠의 원인.

Lu-176: $Q = 8.0\;\text{b}$. Pb-208 인접: $Q \approx 0$. $^{166}\text{Er}$: $\beta_2 \approx 0.34$.

뮤온 X선, 전자 산란으로 $Q$ 측정 $< 5\%$ 정합.

핵 사중극 모멘트, 핵 변형, 변형 매개변수 $\beta_2$, 장타원/편타원

쿨롱 들뜸, 뮤온 원자 X선으로 $Q$ 직접 측정됨.

도메인 비트 비등방에서 $\beta_2$ 값의 정량 도출.

재대입 용도: 재대입 용도: H-653(집단 운동) 변형. H-657(중수소) $Q_d$

5단계 재귀 대입: 도메인 비트 비등방에서 변형 핵 고유 사중극 모멘트 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

핵 사중극 모멘트는 도메인 3공간축(공리 1)에 전하 밀도가 비등방으로 분포할 때 나타난다. FSM 노름이 구면에서 벗어난 변형을 가질 때 그 비용 분포(공리 3)가 변형 매개변수 $\beta_2$로 요약된다.

2단계. 노름 치환

(a) 치환하는 노름은 도메인 비트 비등방 분포의 변형 노름 $\beta_2$다. (b) 이 노름을 택하는 이유는 비구면 변형 비용(공리 4)이 곧 고유 사중극 모멘트 $Q_0$를 정하고, $Q_0$가 $\beta_2$에 1차로 비례하기 때문이다. 고유 사중극 모멘트를 $\beta_2$와 핵 반지름의 함수로 치환한다.

$Q = \dfrac{1}{e}\displaystyle\int \rho(r)(3z^2 - r^2)\,d^3r$
$Q_0 = \dfrac{3}{\sqrt{5\pi}}\,Z R_0^2\,\beta_2,\quad R_0 = 1.2\,A^{1/3}\;\text{fm}$
$Q_0$: 고유 사중극 모멘트 | $Z$: 양성자수 | $R_0$: 핵 반지름 | $\beta_2$: 도메인 비트 변형 노름 | $\rho$: FSM 노름 전하 밀도

3단계. 상수 대입

Z = 68 Er-166 양성자수
A = 166 Er-166 핵자수
$R_{0}$ = 1.2 * $166^(1/3)$ = 6.60 $\text{fm}$
$\beta2$ = 0.34 Er-166 변형 매개변수
$Q_{0}(meas)$ $\sim$ 7.6 b 쿨롱 들뜸 실측

4단계. 도메인 변환

(a) 핵 변형 도메인으로 변환한다. (b) 보려는 것은 변형 핵 $^{166}\text{Er}$의 고유 사중극 모멘트 $Q_0$다. $\beta_2$와 핵 반지름을 대입해 산출한다.

$Q_0 = \dfrac{3}{\sqrt{5\pi}}\cdot 68\cdot(6.60)^2\cdot 0.34 = 761\;\text{fm}^2 = 7.61\;\text{b}$

5단계. 발견

도출값: $Q_0(^{166}\text{Er}) = 7.61\;\text{b}$
측정값: $Q_0 \approx 7.6\;\text{b}$ (쿨롱 들뜸)
오차: $< 5\%$

판정: 가설. 고유 모멘트가 5% 안에서 맞지만 변형 매개변수 $\beta_2$가 외부 입력이고 도메인 비트 비등방에서 직접 도출되지 않아 가설에 머문다. 구형 마법수 핵은 $\beta_2=0$이라 $Q\approx 0$, 비구면 변형이 회전 띠의 원인이다.
