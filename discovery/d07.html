D-07. 카비보 각 $\sin\theta_C$

핵심 발견

D-07: 카비보 각 $\sin\theta_C$

$$\sin\theta_C = \frac{2}{9}\!\left(1 + \frac{\pi\,\alpha}{2}\right) = 0.2248$$

오차: 0.24% (실험값 $0.2243$)

쿼크가 세대를 넘어 혼합되는 비율의 기본 각도. CKM 행렬의 핵심 매개변수다.

$\delta^2 = (\text{time}+\text{space})^2 + (\text{observer}+\text{superposition})^2$에서, CAS가 쿼크 세대 간 전이를 쥐는(juida) 비용의 비율이 카비보 각이다.

$2/9$는 CAS 구조에서 나오는 기본 비율이다. 2 = Compare 자유도, 9 = 완전기술자유도(공리 9: CAS 내부 7 + 괄호 구조 2). CAS Compare가 완전기술자유도에서 차지하는 비율이 쿼크 혼합의 기본 각도를 결정한다.

공리 2(CAS 3단계) ==> 공리 9(완전기술자유도 9) ==> 공리 4(비용) ==> D-01($\alpha$). $2/9$가 기본 비율이고, $\pi\alpha/2$는 CAS의 +를 넘는 비용에서 오는 1차 보정항이다.

$\sin\theta_C = (2/9)(1 + \pi\alpha/2)$. 보정항 없이 $2/9 = 0.2222$로 0.9% 오차. 보정을 넣으면 $0.2248$로 0.24% 오차. $\alpha$가 들어가므로 D-01에 의존하는 1차 재대입이다.

$\sin\theta_C = 0.2248$.

실험값 $0.2243$ 대비 0.24%.

기존 물리학에서 카비보 각은 CKM 행렬의 $V_{us}$ 성분으로, 쿼크의 세대 간 전이 확률을 결정한다. Wolfenstein 전개에서 $\lambda = \sin\theta_C$가 전개 매개변수다. 표준모형에서는 자유 매개변수다.

K 메손 붕괴, 하이퍼론 붕괴, $\tau$ 붕괴에서의 $|V_{us}|$ 측정으로 교차 검증 가능하다. BESIII, NA62 실험이 진행 중이다.

D-08(Wolfenstein $A$)과 조합하면 CKM 행렬의 4개 매개변수 중 2개를 확보한다. CP 위반 크기 도출(D-23)에 재대입된다.

5단계 재귀 대입: CAS Compare가 완전기술자유도에서 점유하는 비율에서 카비보 각 $\sin\theta_C$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

카비보 각은 CAS가 쿼크 세대 간 전이를 쥐는 비용의 비율이다. Compare 자유도 2가 완전기술자유도 $9$(공리 9: CAS 내부 7 + 괄호 구조 2)에서 점유하는 몫 $2/9$가 기본 각도를 정하고, $\alpha$의 +를 넘는 1차 보정(공리 4)이 더해진다.

2단계. 노름 치환

치환하는 노름은 Compare 자유도 2 대 완전기술자유도 9의 비율 노름 $2/9$이다. 카비보 각이 CAS가 쿼크 세대 간 전이를 쥐는 비용의 비율이고, 그 비용이 Compare가 완전기술자유도에서 점유하는 몫으로 닫히기 때문에 이 노름을 택한다. 따라서 카비보 각을 기본 비율 $2/9$와 D-01의 $\alpha$에서 오는 1차 보정으로 치환한다.

$\sin\theta_C = |V_{us}|$
$\sin\theta_C = \dfrac{2}{9}\!\left(1 + \dfrac{\pi\,\alpha}{2}\right)$
$\theta_C$: 카비보 각 | $2$: Compare 자유도 | $9$: 완전기술자유도 = CAS 7 + 괄호 2 (공리 9) | $\pi\alpha/2$: +를 넘는 1차 보정 (D-01) | $V_{us}$: CKM 행렬 성분

3단계. 상수 대입

2/9            = 0.22222
alpha          = 1/137.036          D-01
pi alpha / 2   = 0.011460
sin theta_C    = 0.2243             PDG (V_us)

4단계. 도메인 변환

CKM 혼합각 도메인으로 변환한다. 이 변환으로 보려는 것은 쿼크가 세대를 넘어 섞이는 기본 비율, 곧 카비보 각 $\sin\theta_C$다. 기본 비율 $2/9$에 1차 보정을 곱해 카비보 각을 산출한다. 보정 없이는 $0.2222$로 0.9% 오차다.

$\sin\theta_C = 0.22222 \times (1 + 0.011460) = 0.2248$

5단계. 발견

측정값: $0.2243$ (PDG $V_{us}$)
오차: $0.24\%$

판정: 발견. Wolfenstein 전개 매개변수 $\lambda$였던 자유 매개변수가 Compare/완전기술자유도 비율에서 닫히며, D-08와 결합해 CKM 행렬을 구성하고 CP 위반 D-23에 재투입된다.
