H-440: 체렌코프 복사 = 매질 내 비용 전파 초과

$$\cos\theta_C = \frac{1}{\beta n}$$

등급: B

매질이 CAS 경계에 추가 비용 부과 ==> 비용 전파 속도 $c/n$. 입자가 이를 초과하면 비용 충격파.

공리 4(추가 경계=추가 비용), H-429(광속=비용 상한)

공리 4(추가 경계=추가 비용), H-429(광속=비용 상한), 공리 2(독립 실행)

$\beta n < 1$: 복사 없음. 스펙트럼 $\propto 1/\lambda^2$(짧은 파장=더 많은 경계).

물($n=1.33$): 문턱 $\beta = 0.75$, $\theta_C = 41.2°$.

Super-Kamiokande 등 체렌코프 검출기 데이터와 일치.

5단계 재귀 대입: 매질 비용 전파 초과에서 체렌코프 각 $\cos\theta_C = 1/(\beta n)$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

체렌코프 복사는 입자가 매질 내 비용 전파 속도를 초과할 때 생기는 비용 충격파다. 매질은 CAS 경계에 추가 비용을 부과해 비용 전파 속도를 $c/n$으로 낮추고(공리 4: 추가 경계는 추가 비용), 진공 비용 상한 $c$는 광속(H-429)이므로, 초과 조건을 $\delta^2$ 위 속도 비로 읽는다.

2단계. 노름 치환

(a) 치환하는 노름은 매질 비용 전파 노름으로, 굴절률 $n$이 단위 거리당 추가 경계 수다(공리 4). (b) 이 노름을 택하는 이유는 입자 속도 $\beta c$와 비용 전파 속도 $c/n$의 비가 충격파 원뿔 각을 정하기 때문이다 — 독립 실행되는 CAS 경계들이 같은 위상으로 겹치는 각이 $\theta_C$다(공리 2). 따라서 원뿔 각의 코사인을 두 속도 비로 치환한다.

$\cos\theta_C = \dfrac{c/n}{\beta c} = \dfrac{1}{\beta n}$
$\theta_C$: 체렌코프 원뿔 각 | $\beta$: 입자 속도 $v/c$ | $n$: 굴절률 = 단위 거리당 추가 경계 수(공리 4) | $c/n$: 매질 내 비용 전파 속도(H-429)

3단계. 상수 대입

n(물) = 1.33
$\beta_{th}$ = 1/n = 0.752 문턱 속도
$\cos_\theta$ = $1/(\beta$ n), $\beta=1$ 한계
$\theta_{C}$ = $\arccos(1/1.33)$ = 41.2 deg

4단계. 도메인 변환

(a) 매질 비용 전파 도메인으로 변환한다. (b) 보려는 것은 문턱 조건과 원뿔 각이다. $\beta n < 1$이면 입자가 비용 전파를 못 따라잡아 복사 없음, $\beta n > 1$이면 충격파가 선다. 물 $n=1.33$, 상대론 극한 $\beta=1$에서 각을 산출한다.

$\theta_C = \arccos\dfrac{1}{\beta n} = \arccos\dfrac{1}{1.33} = 41.2^\circ$

5단계. 발견

도출: 문턱 $\beta = 0.75$, $\theta_C = 41.2^\circ$ (물 $n=1.33$)
측정: Super-Kamiokande 등 체렌코프 검출기 데이터
정합: 문턱 속도 및 원뿔 각 일치

판정: 가설. 각 관계는 공리 4에서 닫히나 굴절률 $n$이 매질별 외부 입력이라 forward chain 마지막 단계가 열려 있다.
