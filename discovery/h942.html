H-942. 반정수 스핀 = 사원수 720도 회전 항등성

핵심 발견

H-942: 반정수 스핀 = 사원수 720도 회전 항등성

$$R(360°)\,|\psi_{\text{fermion}}\rangle = -|\psi_{\text{fermion}}\rangle, \quad R(720°)\,|\psi_{\text{fermion}}\rangle = +|\psi_{\text{fermion}}\rangle$$

등급: A (사원수 명제 직격)

페르미온이 왜 1/2 스핀을 갖는가 — 360도 회전이 항등이 아니고 720도 회전이 항등인 이유. 사원수 회전이 단위 사원수 양쪽 곱 (q v q⁻¹) 구조에서 자동 도출.

공리 1 사원수 명제 (v1.6) 에서 공간 3축 = xi + yj + zk. 사원수 회전 작용은 양쪽 곱 ==> 360도 회전 시 q ==> -q (위상 반전), 720도에서 q ==> q (항등). 공리 1 단위원 형식 명제의 (-1)^n 위상 패턴이 3D 회전에 그대로 확장.

공리 1 (직교 4축) ==> 공리 1 사원수 명제 (3축 ==> 단위구) ==> 공리 1 단위원 형식 명제 (i² = -1 패턴) ==> 공리 4 노름 reading (호 = pi). 720도 = 2 × 360도 = 단위 사원수 두 바퀴 = 위상 (-1)² = +1 항등.

페르미온 = 사원수 표현. 보존 = 벡터 표현. 360도에서 페르미온 위상 -1 (스핀 1/2), 보존 위상 +1 (스핀 1). SU(2) ↔ SO(3) 2:1 이중 덮개 = 같은 구조의 군론 표현.

페르미온 스핀 = 1/2, 3/2, 5/2 (반정수). 보존 스핀 = 0, 1, 2 (정수). 4세대 페르미온 부재 = 사원수 단위 i, j, k 외 4번째 단위 부재 (공리 1 사원수 명제 적용 대상 = 3축뿐).

실험적으로 확인됨: 전자 g ≈ 2 (스핀 1/2), Stern-Gerlach 분리, Werner 1985 중성자 회전 720도 항등 직접 측정.

Pauli 1924 스핀, Dirac 1928 방정식 (사원수 동형), Stern-Gerlach 분리, Werner 1985 중성자 간섭 실험

표준모형은 스핀을 입력 매개변수로 받음. "왜 1/2인가" 답 없음. 반야프레임은 사원수 양쪽 곱 구조의 직접 귀결로 도출.

4세대 페르미온이 발견되면 사원수 3 단위 한계 깨짐 ==> 본 가설 부정. P-03 (4세대 부재) 와 동시 검증.

사원수 회전군 SU(2) ↔ 표준모형 약력 SU(2)_L 의 직접 동형 도출. 현재 H-02 부분 매핑.

재대입 용도: 재대입 용도: H-944 (스핀-통계), H-948 (Pauli σ matrices), Dirac equation 도출. P-03 (4세대 부재) 보강.

5단계 재귀 대입: 사원수 양쪽 곱 노름에서 반정수 스핀 $R(720^\circ)=+1$ 도출

1단계. 반야식

$$\delta^2 = (\text{time} + \text{space})^2 + (\text{observer} + \text{superposition})^2$$

스핀은 공간 3축 직교 서브프레임의 회전 비용으로 읽는다. 공리 1 사원수 명제에서 3축 직교 그룹은 단위 사원수로 표현되며, 회전은 단위 사원수의 양쪽 곱 $q v q^{-1}$로 작용한다.

2단계. 노름 치환

(a) 치환하는 노름은 사원수 양쪽 곱 노름이다 — 단위 사원수 $q$가 상태에 $q v q^{-1}$로 작용. (b) 이 노름을 택하는 이유: 페르미온은 공간 3축 직교 그룹(단위 사원수)으로 표현되고, 회전 각도 $\theta$의 작용이 표현 공간에서 $\theta/2$로 나타나기 때문이다. 공리 1 단위원 형식 명제의 위상 $(-1)^n$이 단위구 회전으로 확장돼, 한 바퀴 $360^\circ$에서 위상이 반전된다.

$q = e^{\hat{n}\theta/2}, \quad R(\theta)\,v = q\,v\,q^{-1}$
$R(360^\circ)\,|\psi\rangle = -|\psi\rangle, \quad R(720^\circ)\,|\psi\rangle = +|\psi\rangle$
$q$: 단위 사원수 (공리 1 사원수 명제) | $\hat{n}$: 회전축 단위 순허수부 | $\theta/2$: 양쪽 곱의 반각 | $(-1)^n$: 단위원 위상 (공리 1 명제, 공리 4 노름 reading)

3단계. 상수 대입

theta = 360 deg  -> 반각 180 deg -> 위상 (-1)^1 = -1
theta = 720 deg  -> 반각 360 deg -> 위상 (-1)^2 = +1
s     = 1/2 (페르미온, 사원수 표현)
s     = 0,1 (보존, 벡터/스칼라 표현)

4단계. 도메인 변환

(a) 변환하는 도메인은 공간 회전군 도메인($SU(2)$ 이중 덮개)이다. (b) 보려는 것은 페르미온 상태가 한 바퀴 회전에서 항등이 아닌 이유다. 양쪽 곱의 반각이 $360^\circ$ 회전을 표현 공간 $180^\circ$로 보내므로 위상 $-1$이 되고, 두 바퀴에서야 $+1$ 항등으로 돌아온다.

$R(360^\circ)\,|\psi_{\text{fermion}}\rangle = (-1)^1\,|\psi_{\text{fermion}}\rangle = -|\psi_{\text{fermion}}\rangle$

5단계. 발견

도출: $R(720^\circ) = +1$ 항등, 스핀 $1/2$ (반정수)
측정: Werner 1985 중성자 간섭 $720^\circ$ 항등 직접 확증
정합: 정성 100% (전자 $g\approx 2$, Stern-Gerlach)

판정: 가설. 위상 $(-1)^{2s}$는 사원수 양쪽 곱에서 직접 따라오지만, 스핀 $1/2$ 자체를 정량 식으로 닫는 마지막 단계가 미완이다. 4세대 페르미온 부재(P-03)와 동시 검증된다.
